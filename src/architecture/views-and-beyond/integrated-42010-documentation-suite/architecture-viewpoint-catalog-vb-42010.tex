\docsection{Shared conventions and methods}
Legend L-01 v1.0: rectangles denote named elements with explicit type and stable ID; directed labeled edges denote only the declared relation; nesting means containment only for MK-TREE; an external boundary is labeled; dashed edges require a declared meaning. Non-model text uses labeled fields with ID, source, author, scope, interpretation, and status. Views record versions and known issues. No implicit color semantics.

\textbf{Method} & \textbf{Procedure}\\\midrule
\endhead
VM-01 construct & Collect versioned sources; identify types and relations; select scope; encode model; compare to source; record omissions.\\
VM-02 interpret & Read legend and scope; resolve IDs in catalog; follow only declared edge semantics; distinguish type and instance.\\
VM-03 analyze & Check model-specific constraints; examine scenarios; report unsupported claims and violations.\\
CM-01 realizes & Compare runtime element IDs to implementation catalog and record mappings or violations.\\
CM-02 allocation & Check deployable components against environment mapping; identify missing target.\\
CM-03 coverage & Verify concern, perspective and aspect coverage with explicit view evidence.\\
CM-04 contract & Check connector endpoints, direction and protocol against interface register.\\

\docsection{VP-MD / Module decomposition}
Version 1.0. Family: Module. Typical stakeholder perspective and concern: Engineering / change impact. Aspect: Structural. Typical stakeholders: developers, maintainers and architects.

Governing model kind: MK-TREE; shared legend L-01. Semantics: Containment hierarchy of implementation units; no cycles; each child has one parent in this model.

Construction and use: apply VM-01, VM-02 and VM-03. Select relevant model elements from baseline sources; document catalog, context, variation, rationale and issues. Apply CM-03 for concern coverage; use CM-01 for runtime mapping. Source: V\&B chapter 2; ISO 42010 clause 8.1.

\docsection{Model-kind specifications}
\docsub{MK-TREE / version 1.0}
Nodes are modules; parent-to-child containment. Validation: No containment cycles; at most one parent in this profile. Apply VM-01 through VM-03 and the associated viewpoint correspondence methods. Legend L-01 supplies graphical reading conventions; the typed record is the semantic source. Source: the relevant V\&B style or behavior chapter as mapped above; ISO 42010 8.2.
