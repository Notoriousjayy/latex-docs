\section{Engineering scenario}
The fictional system uses API gateway, stateless compute, event broker, worker, primary database and centralized telemetry.

\section{Prerequisites}
Complete the relevant study guides and ensure you can distinguish module, component-and-connector, and allocation representations. Use a fictional environment or a sanitized, authorized system; never place secrets or sensitive topology into submitted artifacts.

\section{Procedure}
\begin{enumerate}
\item Assign stable runtime IDs, protocols, trust boundaries and principal identities.
\item Model the successful request and an authentication-denied path.
\item Add retry, timeout, duplicate-delivery and backpressure behavior.
\item Define how to detect a broken connection using logs/metrics.
\end{enumerate}
\section{Deliverables}
\begin{itemize}
\item C\&C primary presentation and connector catalog
\item Two interaction traces
\item Failure semantics worksheet
\end{itemize}
