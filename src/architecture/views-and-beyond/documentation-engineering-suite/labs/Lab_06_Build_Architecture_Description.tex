\ArchTitle{Laboratory 06: Integrate the architecture description package}{Hands-on architecture engineering exercise with evidence-based grading}{Practical Laboratory}{ARCH-LAB-06}
\DocProvenance
\section{Engineering scenario}
Combine outputs from prior laboratories into a navigable and reviewable architecture description.

\section{Prerequisites}
Complete the relevant study guides and ensure you can distinguish module, component-and-connector, and allocation representations. Use a fictional environment or a sanitized, authorized system; never place secrets or sensitive topology into submitted artifacts.

\section{Procedure}
\begin{enumerate}
\item Create documentation control, system overview, reader roadmap and glossary.
\item Include at least one view of each of the three structural families.
\item Add element catalog, context, variability and rationale to all selected views.
\item Provide many-to-many correspondence mappings and links to quality scenarios/ADRs.
\end{enumerate}
\section{Deliverables}
\begin{itemize}
\item Architecture description draft
\item Cross-view workbook
\item Release checklist
\end{itemize}

\section{Reflection and critique}
\begin{itemize}
\item What stakeholder question was hardest to answer from the submitted architecture?
\item Which model assumption was most uncertain and how can it be verified?
\item What would need to change in the documentation after a significant runtime revision?
\end{itemize}
