\ArchTitle{Laboratory 02: Build decomposition, uses and layering evidence}{Hands-on architecture engineering exercise with evidence-based grading}{Practical Laboratory}{ARCH-LAB-02}
\DocProvenance
\section{Engineering scenario}
A backend repository contains authentication, API routing, core domain logic, persistence and transport adapters.

\section{Prerequisites}
Complete the relevant study guides and ensure you can distinguish module, component-and-connector, and allocation representations. Use a fictional environment or a sanitized, authorized system; never place secrets or sensitive topology into submitted artifacts.

\section{Procedure}
\begin{enumerate}
\item Define eight modules and responsibilities.
\item Draw is-part-of separately from uses relations.
\item Build an eight-by-eight dependency matrix; calculate cycles using a tool or manual trace.
\item Propose one rule that prevents a forbidden layer dependency and test it.
\end{enumerate}
\section{Deliverables}
\begin{itemize}
\item Module primary presentation
\item Element catalog
\item DSM and violation report
\end{itemize}
