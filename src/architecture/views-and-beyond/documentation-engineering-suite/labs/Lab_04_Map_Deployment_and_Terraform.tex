\DocProvenance
\section{Engineering scenario}
A Terraform-managed AWS environment contains separate network, application and data segments across availability zones.

\section{Prerequisites}
Complete the relevant study guides and ensure you can distinguish module, component-and-connector, and allocation representations. Use a fictional environment or a sanitized, authorized system; never place secrets or sensitive topology into submitted artifacts.

\section{Procedure}
\begin{enumerate}
\item Map each runtime ID to environment, account, subnet or managed resource as appropriate.
\item Trace one service identity to its least-privilege policy evidence.
\item Document zone outage, replacement, and release rollback cases.
\item Compare a proposed view against Terraform plan/state and distinguish declared vs observed runtime.
\end{enumerate}
\section{Deliverables}
\begin{itemize}
\item Deployment allocation view
\item Runtime-to-resource mapping table
\item Drift observation log
\end{itemize}
