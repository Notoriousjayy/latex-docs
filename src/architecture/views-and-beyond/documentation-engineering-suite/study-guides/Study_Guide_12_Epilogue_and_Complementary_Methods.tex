\section{Conceptual focus}
Alternative approaches can be complementary when stakeholder concerns and view semantics are explicit.

\section{Reading map}
Book location: Epilogue. Principal topics: ISO architectural description concepts, 4+1, agile documentation, other approaches. Read the chapter discussion, then its summary checklist and selected discussion questions. Record terms precisely before adapting them to an implementation.

\section{Learning objectives}
\begin{itemize}
\item Explain ISO architectural description concepts, 4+1, agile documentation, other approaches in terms of a stakeholder question.
\item Keep standards-era claims qualified; explain translations rather than equating unlike viewpoints.
\item Separate book-supported architectural concepts from optional implementation techniques such as Terraform, OpenAPI, and CI-generated evidence.
\end{itemize}
