\section{Purpose and use}
Score the evidence, not the apparent elegance of the diagram. For each criterion assign a raw rating 0--4: 0 = absent; 1 = asserted with little support; 2 = partial; 3 = demonstrably sufficient; 4 = strong with independent verification. Weighted points = criterion weight times rating divided by four. Total maximum is 100.

\section{Example calculation}
A criterion weighted at 20 points with evidence rated 3/4 contributes 15 points. A 75/100 total is a useful descriptive value, not an automatic release decision: unresolved critical safety or security gaps still require disposition.

\section{Release-gate recommendations}
\begin{itemize}
\item Accept only when stakeholder-specific documentation purposes can be demonstrated.
\item Document any criterion rated zero or one and assign a remediation owner.
\item Do not waive critical unverified security or availability claims solely due to a good aggregate score.
\item Record evidence versions, assessor, independent review and next assessment trigger.
\end{itemize}
