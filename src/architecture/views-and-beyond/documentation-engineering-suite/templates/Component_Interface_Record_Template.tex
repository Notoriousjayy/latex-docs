\section{When to use this artifact}
Use this form to document one controlled unit of architectural evidence. The template contains instructional prompts. The companion blank is deliberately unfilled and suitable for printing or handwritten completion.

\section{Contract identity and ownership}
Declare component, consumer, interface ID, version, environment and lifecycle status.

\BlankLines{2}
\section{Provided and required operations}
List operations/messages, calling convention, endpoint or protocol.

\BlankLines{2}
\section{Data schema and semantic rules}
Provide field types, nullability, units, ordering, idempotency, consistency and constraints.

\BlankLines{2}
\section{Authentication and authorization}
Specify principal type, trust boundary, permitted access and audit policy.

\BlankLines{2}
\section{Preconditions and postconditions}
Define expected initial state and observable outcomes.

\BlankLines{2}
\section{Error contract and recovery}
Document status codes, retryability, timeouts, backpressure and partial failures.

\BlankLines{2}
\section{Compatibility and evolution}
Define version policy, deprecation behavior and consumer obligations.

\BlankLines{2}
\section{Contract verification}
Identify positive, negative, security, and interoperability tests; link evidence.

\BlankLines{2}
\section{Template completion checklist}
\begin{itemize}
\item Identifiers are stable and references resolve.
\item Every materially important claim has a source, reviewer, or explicit assumption.
\item No uncontrolled secrets, internal credentials, or sensitive data are published.
\item Status and decision authority are recorded.
\end{itemize}
