\section{Trace and verify}
\begin{itemize}
\item Every relation has a typed meaning
\item Each runtime deployment maps to a software or external owner
\item Source and target IDs exist at captured revisions
\item Boundary exceptions are approved
\end{itemize}
\section{Instructions for analysis}
\begin{itemize}
\item Populate one row per relation or claim, not one row per diagram.
\item Where evidence is absent, record an explicit gap and owner.
\item Review both source-to-target and target-to-source traversal.
\item Recheck changed source artifacts before reusing prior assessments.
\end{itemize}
