\section{Security and operational validation}
\Field{Security test references}{Record audit logs, permissions review, and privacy treatment.}
\Field{Reliability and load test references}{Record retry/backoff, API budget and recovery evidence.}
\subsection{Control checklist}
\begin{itemize}
\item $\square$ GitHub App permissions are read-only and scoped to authorized repositories
\item $\square$ No source workflow or third-party action is executed
\item $\square$ Token values and private contents absent from logs
\item $\square$ Rate limiting, backoff and checkpoint restart tested
\item $\square$ Repeated pinned scans produce equivalent normalized facts
\item $\square$ Access denied, missing, truncated and malformed states distinguished
\item $\square$ Evidence graph exports have appropriate access controls
\end{itemize}
