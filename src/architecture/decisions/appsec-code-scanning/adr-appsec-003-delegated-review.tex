{\LARGE\bfseries ADR-APPSEC-003 Prefer delegated review over direct dismissal}\par
\textbf{Status: PROPOSED (not approved)}\par
\textbf{Decision owner:} To be assigned by an adopting organization.\par
\textbf{Scope:} Enterprise GitHub code scanning companion to architecture discovery.
\section{Context}
GitHub's direct code scanning dismissal changes alert state across branches; the delegated request mechanism preserves explicit reviewer authority and request provenance.
\section{Alternatives}
\begin{itemize}
\item Direct PATCH automation: fast, broad authority and cross-branch blast radius.
\item Delegated dismissal with independent reviewer: stronger separation but feature/version prerequisites.
\item Manual-only: lower automation risk but ongoing operational cost.
\end{itemize}
\section{Proposed decision}
Design for delegated dismissal as the future production path; no executable approval until edition, permission and role verification and formal approval.
\section{Consequences, validation and reversibility}
Use independent approval identity, policy hash, execution recheck, audit ledger and manual override. Keep direct dismissal exceptional and separately governed.
\section{Authorization}
No deployment, API mutation or policy change is authorized by this draft ADR. Acceptance requires named independent security and platform reviewers, environment-specific API verification and controlled pilot evidence.
