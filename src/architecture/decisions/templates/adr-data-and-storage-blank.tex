\section{Domain-specific decision inputs}
Complete the following prompts with referenceable designs, measurements,
threat assessments or operational constraints; mark inapplicable prompts
explicitly rather than removing necessary decision context.
\begin{itemize}
\item Entities, data owners, classification, growth, workload shape, access patterns, query cardinality and latency.
\item Data architecture: transactional, document, key-value, object, event stream or analytical storage; placement and indexing.
\item Consistency, transaction boundaries, concurrency control, idempotency, ordering and conflict resolution.
\item Schema evolution, backward/forward compatibility, migration sequencing, backfill and dual-write hazards.
\item Retention, records management, deletion, encryption, backup integrity, restore and cross-region access.
\end{itemize}
