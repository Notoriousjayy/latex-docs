\subsection{Complete the worksheet}
\begin{enumerate}
\item Replace every \FillIn{bracketed field} with the selected viewpoint's content.
Use stable identifiers and record the source and version of adopted conventions.
\item Repeat catalogue rows and detailed records for each concern, stakeholder
role, model kind, view method, and correspondence method.
\item State applicability and limitations. Where a field is unresolved, identify
the gap, responsible role, and evidence needed to resolve it.
\item Use the companion viewpoint guide for interpretation and examples.
Include or reference the completed specification from the relevant AD.
\end{enumerate}

\subsection{Worksheet contents}
The records cover identity and scope; concerns and audience; model kinds;
legends and other formats; view methods; correspondences; and examples,
sources, and stewardship.

\subsection{Template status}
The colored fields are intentionally unfilled. They are authoring prompts,
not a completed viewpoint or a certification checklist. This standalone
document contains the same worksheet body supplied as the reusable viewpoint section.

\subsection{Ways to specify the conventions}
\begin{itemize}
\item Reference an existing language or notation and identify the adopted version
and any local restrictions or extensions.
\item Define a metamodel covering concepts, properties, relationships, and
constraints, with an explanation of its interpretation.
\item Supply a structured model template, an explicit vocabulary, and rules for
its use. Combine these approaches where that gives a clearer specification.
\end{itemize}
\Guide{A constraint on permissible notation is different from a constraint on the
entity being described. Record which kind of constraint each statement expresses.}

\subsection{Suggested construction sequence}
\begin{enumerate}
\item Establish the entity scope, architecture baseline, audience, and concern set.
\item Collect and identify the source information used by the selected component formats.
\item Construct the representations using the specified vocabulary, conventions, and legends.
\item Apply the defined analysis and correspondence methods; retain their evidence.
\item Record findings, assumptions, limitations, and unresolved issues with the view.
\end{enumerate}
\Guide{This sequence is an authoring aid. Replace it with a documented method
appropriate to the viewpoint. Include implementation guidance only where the
viewpoint actually supports that use.}
