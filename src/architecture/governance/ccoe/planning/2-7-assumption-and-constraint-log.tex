\docsection{03 \quad Source diagnostic checklist}
\textit{The following questions are preserved as diagnostic prompts from the original file, including any broad or sector-specific wording. They do not indicate that a condition has been verified. Mark N/A where not applicable.}
\begingroup\small\begin{enumerate}[leftmargin=2.1em, itemsep=4pt]
\item[1.] How do you design an auditing system?
\item[2.] Has a Cloud Center of Excellence project Communications Plan been developed?
\item[3.] What worked well?
\item[4.] Are processes for release management of new development from coding and unit testing, to integration testing, to training, and production defined and followed?
\item[5.] Were the system requirements formally reviewed prior to initiating the design phase?
\item[6.] No superfluous information or marketing narrative?
\item[7.] Have all necessary approvals been obtained?
\item[8.] Are formal code reviews conducted?
\item[9.] Do documented requirements exist for all critical components and areas, including technical, business, interfaces, performance, security and conversion requirements?
\item[10.] What do you log?
\item[11.] Have Cloud Center of Excellence project management standards and procedures been established and documented?
\item[12.] What would you gain if you spent time working to improve this process?
\item[13.] Is staff trained on the software technologies that are being used on the Cloud Center of Excellence project?
\item[14.] Are there ways to reduce the time it takes to get something approved?
\item[15.] What other teams / processes would be impacted by changes to the current process, and how?
\item[16.] Have all involved stakeholders and work groups committed to the Cloud Center of Excellence project?
\item[17.] Does a specific action and/or state that is known to violate security policy occur?
\item[18.] Are there unnecessary steps that are creating bottlenecks and/or causing people to wait?
\item[19.] How are new requirements or changes to requirements identified?
\item[20.] When can log be discarded?
\item[21.] If it is out of compliance, should the process be amended or should the Plan be amended?
\item[22.] Is this process still needed?
\item[23.] Are there standards for code development?
\item[24.] Are there processes in place to ensure internal consistency between the source code components?
\end{enumerate}\endgroup
