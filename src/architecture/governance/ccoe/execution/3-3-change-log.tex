\docsection{03 \quad Source diagnostic checklist}
\textit{The following questions are preserved as diagnostic prompts from the original file, including any broad or sector-specific wording. They do not indicate that a condition has been verified. Mark N/A where not applicable.}
\begingroup\small\begin{enumerate}[leftmargin=2.1em, itemsep=4pt]
\item[1.] Is this a mandatory replacement?
\item[2.] When was the request submitted?
\item[3.] How does this relate to the standards developed for specific business processes?
\item[4.] Who initiated the change request?
\item[5.] Will the Cloud Center of Excellence project fail if the change request is not executed?
\item[6.] Does the suggested change request seem to represent a necessary enhancement to the product?
\item[7.] Is the change request open, closed or pending?
\item[8.] Is the change request within Cloud Center of Excellence project scope?
\item[9.] How does this change affect scope?
\item[10.] Does the suggested change request represent a desired enhancement to the products functionality?
\item[11.] How does this change affect the timeline of the schedule?
\item[12.] Is the requested change request a result of changes in other Cloud Center of Excellence project(s)?
\item[13.] Should a more thorough impact analysis be conducted?
\item[14.] Where do changes come from?
\item[15.] Is the submitted change a new change or a modification of a previously approved change?
\item[16.] Do the described changes impact on the integrity or security of the system?
\item[17.] When was the request approved?
\item[18.] Is the change backward compatible without limitations?
\end{enumerate}\endgroup
