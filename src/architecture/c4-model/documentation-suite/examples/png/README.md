# C4 Model: PNG Examples

Raster renders of the [C4 diagram examples](../README.md), supplied as viewing/reference assets. The diagrams show the civic-permit sample at context, container, component, dynamic, and deployment scopes.

The five PNG files are generated or illustrative assets; consult the source diagrams for authoritative edits and regenerate assets rather than hand-modifying the images.
