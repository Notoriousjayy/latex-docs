# C4 Model and Architecture Visualization

This architecture domain collection contains the [C4 Model and Software Architecture Visualization Documentation Suite](documentation-suite/README.md).

The suite includes 12 original chapter-aligned study guides, a prerequisite curriculum, technical references, viewpoints, hands-on PlantUML laboratories, diagram specifications, review scorecards, and 15 Template–Blank form pairs. The source book is not redistributed.

**Source integrity:** Book-aligned C4 concepts are distinguished from supplementary engineering methods, including architecture traceability, CI validation, security reviews, ISO/IEC/IEEE 42010 integration, UML, and *Views and Beyond*.

Use the [suite README](documentation-suite/README.md) for reading order, validation, and repository integration. For canonical diagram styling see [`tooling/plantuml/README.md`](../../../tooling/plantuml/README.md).
