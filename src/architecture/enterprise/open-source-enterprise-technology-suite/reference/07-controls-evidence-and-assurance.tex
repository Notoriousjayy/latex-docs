\section{Control to process relationship}
\begin{itemize}
\item Every control has a control ID, accountable owner, applicability decision, periodic test method, evidence URI and next-review date.
\item Evidence retains raw source identity, date, cryptographic digest, scope and access decision.
\item Exceptions cannot be approved by the same actor who requests them; use compensating control and expiry.
\item NIST CSF function labels in the source registry are broad thematic mappings, not official subcategory mappings or compliance certification.
\end{itemize}
\section{Assurance test program}
\begin{enumerate}
\item Sample one privileged-user lifecycle and one denied access test.
\item Select one production artifact and reproduce its SAST/SBOM release trail.
\item Select one AppSec finding and reconstruct raw evidence, service, risk and verified closure.
\item Select one service outage and follow alert, ticket, root cause, change and recovery record.
\item Select one financial export and confirm business approval and removal of transaction-level data.
\item Reperform an encrypted restore and inspect evidence access logs.
\end{enumerate}
