\section{Management cadences}
\begin{itemize}
\item Daily: pipeline failures, queue age, privileged authentication anomalies and backup health.
\item Weekly: risk-based finding triage, sprint delivery and drift reconciliation.
\item Monthly: patch/upgrade window, access review exceptions, control evidence integrity and SLO review.
\item Quarterly: restore exercise, license/SBOM refresh, architecture decision review and service ownership recertification.
\end{itemize}
\section{Change and incident process}
\begin{enumerate}
\item Log and classify the change or incident in iTop; reference affected CIs.
\item Approve security-sensitive change with rollback and access impact review.
\item Update Taiga implementation tasks when change creates delivery work.
\item During incidents, preserve forensic evidence separately from customer-facing communications.
\item Reconcile GRC risks, SLO breach and residual actions after closure.
\end{enumerate}
