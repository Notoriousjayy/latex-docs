\section{Event envelope schema}
\begin{itemize}
\item schema\_version: semantic version of event contract; decline unsupported breaking versions.
\item event\_id: immutable UUID/ULID; event\_type; occurred\_at in UTC; ingested\_at; correlation\_id.
\item tenant\_id and source\_system: required to prevent cross-tenant matching.
\item subject: entity\_type, canonical\_id, external\_reference and source\_version.
\item payload\_ref: immutable storage pointer and SHA-256 digest; never inline secrets, bank transactions or personal records.
\item trace: actor, applied\_policy\_version, decision and approval reference.
\end{itemize}
\section{Retries and reconciliation}
\begin{itemize}
\item Authenticate integrations with application-specific least-privilege credentials and egress allowlists.
\item Validate payloads, signature/authentication, timestamp tolerance and content type before processing.
\item Write raw evidence once, commit outbox state, then deliver downstream by stable idempotency key.
\item Use bounded exponential retry with jitter, dead-letter queue, manual replay and dashboards for delivery failures.
\item Reconcile source-to-target counts daily and classify unknown/missing/deleted/retired states separately.
\item Never infer closure from story status alone: require rescan or approved compensating control.
\end{itemize}
\section{Contract acceptance tests}
\begin{enumerate}
\item Map and resolve known identity aliases; reject a deliberate collision.
\item Send duplicate payload and assert one authoritative finding + one Taiga work item.
\item Inject 429/5xx, lost acknowledgement and out-of-order events; assert safe retry and provenance.
\item Delete a source entity and assert tombstone/retention policy not silent data loss.
\item Attempt overprivileged and cross-tenant calls; assert denial and audit record.
\item Inspect redacted logs and encrypted stored payload access.
\end{enumerate}
