\section{Decision method}
\begin{itemize}
\item Record stakeholders, tradeoffs, alternatives and deferred decisions as standalone ADRs.
\item Attach the 10+ templates and scorecards to review evidence; blanks must not be marked as completed evidence.
\item Set a mandatory reevaluation trigger for vendor/edition or protocol changes.
\item Use one common revision identifier and make source evidence immutable at approval time.
\end{itemize}
\section{Readiness thresholds}
\textbf{Decision / gate.} Production candidate requires no open hard-gate failure, approved exceptions with expiry, verified restore and integration negative tests, and named 24/7 escalation where needed.\par
