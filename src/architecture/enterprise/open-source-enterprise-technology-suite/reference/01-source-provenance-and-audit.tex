\section{Primary interpretation rules}
\begin{itemize}
\item Source architecture is a proposal, not evidence that an integration has already been built or tested.
\item Keep upstream links, license evidence, release hashes and assessment timestamps with product records.
\item The security report itself labels some catalog entries as discovery candidates; do not upgrade to production-approved by copying them.
\item Financial handout is not an enterprise ERP comparison. Its tools must not be assumed to support statutory accounting, payroll, tax, inventory or multi-entity controls.
\item This suite adds original decision, integration and control methodology beyond the original handouts.
\end{itemize}

\section{Evidence confidence scale}
\begin{itemize}
\item E0: architecture hypothesis without upstream/operational proof.
\item E1: documented vendor or project feature claim, current URL and review date.
\item E2: reproduced in a versioned sandbox or test environment with retained logs.
\item E3: validated in an approved operational environment with owner and rollback plan.
\end{itemize}
\textbf{Decision / gate.} Default confidence of new connector designs is E0 until evidence is recorded.\par
