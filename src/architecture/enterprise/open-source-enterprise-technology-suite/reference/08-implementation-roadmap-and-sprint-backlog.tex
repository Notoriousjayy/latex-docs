\section{Definition of Ready}
\begin{itemize}
\item Story names one authoritative system and actor and includes bounded scope.
\item Dependencies, data class, privilege model and acceptance evidence known.
\item Owner agrees on implementation route and estimated points; security and operations constraints identified.
\end{itemize}
\section{Definition of Done}
\begin{itemize}
\item Functional tests and negative authorization tests pass.
\item Identity mapping, idempotency, retry, audit and recovery behavior demonstrated.
\item Security findings are linked to owning service and remediation; no orphan evidence.
\item Runbook, monitoring and rollback are updated; compliance evidence is discoverable.
\end{itemize}
\section{Release go/no-go}
\textbf{Decision / gate.} No production rollout when license status is unknown, finance data boundary is violated, critical integrations silently lose events, or backup restore is untested.\par
