\textbf{Purpose and status.} Operator procedure; adapt scope, access and escalation to the production environment.\par
\textbf{Evidence status:} Proposed / requires local validation.\par
\section{Preconditions}
\begin{itemize}
\item Approved maintenance window, RTO/RPO targets, service dependency map and recovery operator access.
\item Encrypted backup snapshot and independently stored decryption/recovery keys; test environment isolated.
\end{itemize}
\section{Procedure}
\begin{enumerate}
\item Capture starting timestamp, backup inventory, hashes and recovery objectives.
\item Restore secrets and identity to isolated test; revoke production network egress.
\item Restore databases and attachments by dependency order, then applications and queues.
\item Verify login authorization, raw-evidence digests, GLPI/iTop link integrity and Taiga story status.
\item For finance, validate ledger totals and access separation without copying private transactions into generic logs.
\item Record measured data loss and time to service; record deviations and remediation.
\end{enumerate}
\section{Failure handling}
\begin{itemize}
\item If keys inaccessible or restore exceeds objectives, document failure and initiate risk treatment.
\item Do not declare restore successful based only on exit code.
\end{itemize}
