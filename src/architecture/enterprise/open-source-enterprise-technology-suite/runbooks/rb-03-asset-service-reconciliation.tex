\textbf{Purpose and status.} Operator procedure; adapt scope, access and escalation to the production environment.\par
\textbf{Evidence status:} Proposed / requires local validation.\par
\section{Boundaries}
\begin{itemize}
\item GLPI owns hardware/software inventory attributes when selected; iTop owns CI dependency and service model.
\item Owner field is mastered in one system only; define field-by-field crosswalk.
\end{itemize}
\section{Procedure}
\begin{enumerate}
\item Capture incremental changes with source timestamp and immutable external ID.
\item Map aliases and authoritative attributes via documented transform and schema contract.
\item Quarantine one-to-many or missing-ID matches; do not auto-create critical services on name similarity.
\item Apply idempotent update; log source revision and target response.
\item Compare record counts, lifecycle and sample attribute values; create iTop incident for persistent mismatch.
\item Review retired/merged assets and tombstones before deleting any downstream CI link.
\end{enumerate}
\section{Evidence}
\begin{itemize}
\item Daily reconciliation report, match confidence, conflict queue and resolution signer.
\item Manual correction request returns to authoritative system rather than editing the replica.
\end{itemize}
