\textbf{Purpose and status.} Operator procedure; adapt scope, access and escalation to the production environment.\par
\textbf{Evidence status:} Proposed / requires local validation.\par
\section{Triggers}
\begin{itemize}
\item Unapproved transaction export, bank-sync credential leak, finance app exposed to public network, or finance data in AppSec logs.
\item Identify account owner and privacy/security incident response lead.
\end{itemize}
\section{Immediate actions}
\begin{enumerate}
\item Revoke suspected tokens/sessions using approved break-glass process; minimize further exposure.
\item Preserve relevant forensic events without reproducing unmasked transaction data in tickets.
\item Determine affected records, backup copies, connector permissions and disclosure obligations with legal/privacy team.
\item Quarantine integrations and restore boundary, encrypt new evidence and record access approvals.
\item Reissue credentials, validate negative authorization, update rules and retest monitoring.
\end{enumerate}
\section{Closure evidence}
\begin{itemize}
\item Incident ID, data scope, containment time, credential rotation and verified access boundary.
\item Required notices, retention exceptions and lessons learned are determined by applicable jurisdiction and policy.
\end{itemize}
