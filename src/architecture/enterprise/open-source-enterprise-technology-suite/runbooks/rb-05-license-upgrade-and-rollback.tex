\section{Preflight}
\begin{itemize}
\item Release version, artifact SHA, SBOM, exact OSI/open-core/commercial license determination.
\item Change ticket, compatibility review, security advisories and tested rollback package.
\end{itemize}
\section{Procedure}
\begin{enumerate}
\item Verify upstream signatures/digests and reviewed dependency tree.
\item Validate feature availability and integration API/SSO changes in staging.
\item Exercise application export, encrypted backup and restore before production migration.
\item Apply change in approved window; verify authentication, ingest, key dashboards, retries and evidence history.
\item When acceptance fails, stop writes, restore compatible schema/data and verify downstream replay.
\item Record completed release evidence or rollback reason and create follow-up actions.
\end{enumerate}
\section{Guardrails}
\begin{itemize}
\item Never upgrade a live finance database without validated rollback compatibility.
\item Unknown licensing or missing provenance blocks deploy; available download is not approval.
\end{itemize}
