\section{Scope}
The companion private Taiga repository contains 42 planned stories, 210 implementation tasks and prerequisite links. Nothing in this document implies these stories were imported, estimated, assigned, or accepted.

\section{Prerequisite order}
G1 account boundaries precede G2 IAM and egress controls. G3 state and secrets precede G4 repeatable Terraform composition. G5 measures operations and recovery. G6 safeguards delivery and production promotion; CI static validation may begin earlier in parallel.

\section{Acceptance, estimation and evidence}
Each story has a value-centered narrative, dependency list, multiple measurable acceptance criteria, a task checklist, negative-test expectations and evidence requirements. Stories remain unestimated pending team refinement. Requirements are traceable to the architecture guide and actual Terraform paths.

\section{Recommended first iteration}
Review account ownership and isolation ADR-0001, shared responsibility, threat model, CI federation boundaries, and separate state bootstrap prerequisites. Do not perform unauthorized AWS applies or Taiga write operations.
