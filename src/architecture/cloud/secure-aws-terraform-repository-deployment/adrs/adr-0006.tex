{\LARGE\bfseries\color{Navy} ADR-0006: Separate validation and deployment trust }\\[4mm]
\textbf{Status: Proposed} \quad | \quad 29 October 2026 \quad | \quad Owner: Architecture Governance
\end{center}
\hrule
\section*{Context}
Untrusted pull-request content can execute arbitrary build/test scripts. Giving it deployment credentials risks cloud compromise.
\section*{Decision}
Unprivileged PR checks and protected OIDC deployments from reviewed commits.
\begin{enumerate}[leftmargin=*]
\item Pull request validation runs without AWS deployment credentials and no id-token write permission.
\item Deployment requires reviewed main-branch commit, protected environment, exact account binding, and approved change.
\item Production applies an exact saved Terraform plan within the same approved job or via a higher-assurance integrity-bound plan promotion mechanism.
\item Third-party workflow actions require reviewed immutable refs or supported dependency lockfiles.
\end{enumerate}
\section*{Alternatives considered}
\begin{itemize}[leftmargin=*]
\item Deploying from pull\_request or pull\_request\_target with secrets: rejected.
\item Applying unreviewed pull-request binary plans: rejected.
\item Using a GitHub environment without branch/reviewer protection: rejected.
\end{itemize}
\section*{Consequences}
\begin{itemize}[leftmargin=*]
\item Extra governance may increase deployment latency and require platform support.
\item Reduces untrusted-code privilege and produces stronger audit evidence.
\end{itemize}
\section*{Verification and review triggers}
\begin{enumerate}[leftmargin=*]
\item Verify PR jobs cannot request prod OIDC credentials.
\item Prove main branch, reviewer gate, IAM trust and expected account match at deploy time.
\end{enumerate}
\section*{Decision review}
Review at each quarterly architecture governance checkpoint or whenever organization, cloud, Terraform or GitHub platform constraints materially change. Exceptions require recorded owner, approval and expiration.
