\textbf{Why does the network still matter?} & Packet routing, application protocols, bandwidth and latency constrain cloud service quality regardless of where compute is located.\\[3pt]\textcolor{petrol}{\emph{Practice:} Trace a request from client to workload and record three latency sources.}\\[8pt]\midrule
\textbf{What enables cloud data centers?} & Standardized resources, virtualization, network fabrics, shared storage, remote management and high-availability practices enable pooled operation.\\[3pt]\textcolor{petrol}{\emph{Practice:} Build a layer diagram of a cloud data center.}\\[8pt]\midrule
\textbf{What is the hypervisor's role?} & A hypervisor mediates virtual servers and physical hardware resources. Administrative compromise or host faults may affect multiple guests.\\[3pt]\textcolor{petrol}{\emph{Practice:} Define host and guest isolation verification steps.}\\[8pt]\midrule
\textbf{How do containers differ from virtual machines?} & A container generally shares its host's kernel while virtual machines receive virtualized hardware resources. Choose based on workload isolation, compatibility and operational constraints.\\[3pt]\textcolor{petrol}{\emph{Practice:} State a reason to use each form of hosting.}\\[8pt]\midrule
\textbf{What does multitenancy demand?} & Shared compute must preserve logical separation, resource fairness and policy consistency among consumers.\\[3pt]\textcolor{petrol}{\emph{Practice:} Write a noisy-neighbor and cross-tenant isolation test.}\\[8pt]\midrule
\textbf{Why are service APIs foundational?} & REST, web services, middleware and RPC supply ways to expose capabilities and connect cloud resources through contracts.\\[3pt]\textcolor{petrol}{\emph{Practice:} Draft an interface contract including identity, errors and versioning.}\\[8pt]\midrule
