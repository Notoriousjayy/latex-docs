\textbf{How are boundaries implemented?} & Logical network perimeters restrict exposure between administrative or trust zones while a cloud-based resource may still reside on shared hardware.\\[3pt]\textcolor{petrol}{\emph{Practice:} Draw an ingress, east-west and egress policy plan.}\\[8pt]\midrule
\textbf{What is a virtual server and hypervisor relationship?} & The virtual server is a guest execution environment; the hypervisor provides virtualization capabilities on a physical host.\\[3pt]\textcolor{petrol}{\emph{Practice:} Identify patching responsibility at guest and host layers.}\\[8pt]\midrule
\textbf{Why are storage interfaces not interchangeable?} & Object, database and network/block-style interfaces impose different semantics for addressing, operations and data access.\\[3pt]\textcolor{petrol}{\emph{Practice:} Choose storage for an immutable object and for transactional records.}\\[8pt]\midrule
\textbf{What is a cloud usage monitor?} & It captures consumption observations via agents or polling. Measurements can support scaling, reporting and later cost analysis.\\[3pt]\textcolor{petrol}{\emph{Practice:} Design a sampling and attribution schema.}\\[8pt]\midrule
\textbf{How does resource replication support architectures?} & Copying or recreating a resource can add capacity or redundancy, but replication alone does not guarantee correct routing or data consistency.\\[3pt]\textcolor{petrol}{\emph{Practice:} Describe a replication-consistency test.}\\[8pt]\midrule
\textbf{When is a ready-made environment useful?} & A prescribed runtime accelerates deployment but constrains configuration and operational control.\\[3pt]\textcolor{petrol}{\emph{Practice:} Record portability and patch ownership before adoption.}\\[8pt]\midrule

\section{Synthesis and architecture connections}
Treat each mechanism as a deployable capability, not a complete architecture. Identify the infrastructure prerequisite, management-plane owner, dependent controls and the negative/failure evidence expected from an implementation.
\begin{workbox}[title={Applied deliverable}]
Compose baseline infrastructure mechanisms into a deployable environment.\\[4pt]Create a one-page architecture or operations artifact with: (1) assumptions, (2) a decision and alternatives, (3) control ownership, (4) observable acceptance criteria, and (5) a failed-case test.
\end{workbox}
