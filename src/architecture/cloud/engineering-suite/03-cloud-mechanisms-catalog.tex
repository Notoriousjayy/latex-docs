\section{How to use this catalog}
A mechanism is a recognizable technology capability, not a full production design. The source groups 48 mechanisms under infrastructure, specialized, access-oriented security, data-oriented security and management. The catalog preserves those names and printed source locations. Operational questions and tests are new engineering guidance.
\begin{takeaway}
For each mechanism, document (a) what service need it serves, (b) its owner and configuration source, (c) dependencies and trust boundaries, (d) an explicit negative or failure test, and (e) evidence from the test.
\end{takeaway}
\section{Cloud infrastructure mechanisms}
\Needspace{7\baselineskip}\subsection{Logical Network Perimeter}
Logically separates cloud resources and applies rules to inbound and outbound communication.\\[4pt]
\textbf{Design decision:} Define allowed traffic across each trust boundary.\\[3pt]
\textbf{Verification evidence:} Deny-by-default flow test and rule review.\\[3pt]
\sourceRef{8}{196}
\Needspace{7\baselineskip}\subsection{Virtual Server}
Provides a software-defined server environment on shared physical compute.\\[4pt]
\textbf{Design decision:} Choose sizing, image hardening and administrator access controls.\\[3pt]
\textbf{Verification evidence:} Build manifest, baseline scan and startup timing.\\[3pt]
\sourceRef{8}{200}
\Needspace{7\baselineskip}\subsection{Hypervisor}
Mediates virtual machines and their underlying host resources.\\[4pt]
\textbf{Design decision:} Specify isolation, lifecycle and host administration ownership.\\[3pt]
\textbf{Verification evidence:} Host configuration audit and guest isolation evidence.\\[3pt]
\sourceRef{8}{205}
\Needspace{7\baselineskip}\subsection{Cloud Storage Device}
Exposes storage capacity through file, object, block or database-facing interfaces.\\[4pt]
\textbf{Design decision:} Select an interface from persistence, consistency and access requirements.\\[3pt]
\textbf{Verification evidence:} Restore exercise and access policy test.\\[3pt]
\sourceRef{8}{207}
\Needspace{7\baselineskip}\subsection{Cloud Usage Monitor}
Observes resource consumption by an agent or polling-based monitoring approach.\\[4pt]
\textbf{Design decision:} Identify dimensions, sampling and observability ownership.\\[3pt]
\textbf{Verification evidence:} Sample usage log reconciled with a request workload.\\[3pt]
\sourceRef{8}{214}
\Needspace{7\baselineskip}\subsection{Resource Replication}
Produces additional resource instances to increase capacity or redundancy.\\[4pt]
\textbf{Design decision:} Define triggers, replication scope and convergence behavior.\\[3pt]
\textbf{Verification evidence:} Scale-out and rebuild demonstration.\\[3pt]
\sourceRef{8}{220}
\Needspace{7\baselineskip}\subsection{Ready-Made Environment}
Supplies a preconfigured execution or deployment environment for workloads.\\[4pt]
\textbf{Design decision:} Document runtime limits, portability and patch responsibility.\\[3pt]
\textbf{Verification evidence:} Clean deployment from declared configuration.\\[3pt]
\sourceRef{8}{224}
\Needspace{7\baselineskip}\subsection{Container}
Packages application execution into an isolated hosted runtime unit.\\[4pt]
\textbf{Design decision:} Set immutable image provenance and kernel-sharing risk assumptions.\\[3pt]
\textbf{Verification evidence:} Image provenance, resource limits and runtime smoke test.\\[3pt]
\sourceRef{8}{226}

\section{Data-oriented security mechanisms}
\Needspace{7\baselineskip}\subsection{Digital Virus Scanning and Decryption System}
Scans data and may decrypt content for supported malware inspection workflows.\\[4pt]
\textbf{Design decision:} Balance scanning coverage with encryption and privacy constraints.\\[3pt]
\textbf{Verification evidence:} Known-safe test samples and encrypted-content handling test.\\[3pt]
\sourceRef{11}{312}
\Needspace{7\baselineskip}\subsection{Malicious Code Analysis System}
Examines software artifacts or behavior for malicious characteristics.\\[4pt]
\textbf{Design decision:} Define quarantine, analysis isolation and response process.\\[3pt]
\textbf{Verification evidence:} Controlled analysis report with provenance.\\[3pt]
\sourceRef{11}{315}
\Needspace{7\baselineskip}\subsection{Data Loss Prevention (DLP) System}
Applies controls against unauthorized sensitive-data movement.\\[4pt]
\textbf{Design decision:} Classify data and define enforcement points and exceptions.\\[3pt]
\textbf{Verification evidence:} Test sensitive-data exfiltration and exception workflow.\\[3pt]
\sourceRef{11}{317}
\Needspace{7\baselineskip}\subsection{Trusted Platform Module (TPM)}
Provides a hardware-rooted trust capability for keys and platform measurement.\\[4pt]
\textbf{Design decision:} Specify attestation expectation and key-binding dependencies.\\[3pt]
\textbf{Verification evidence:} Measured-boot or key-unseal evidence.\\[3pt]
\sourceRef{11}{319}
\Needspace{7\baselineskip}\subsection{Data Backup and Recovery System}
Creates recoverable copies and restores lost data or workloads.\\[4pt]
\textbf{Design decision:} Set recovery points, retention, immutability and restore ownership.\\[3pt]
\textbf{Verification evidence:} Timed restoration meeting RPO and RTO objectives.\\[3pt]
\sourceRef{11}{320}
\Needspace{7\baselineskip}\subsection{Activity Log Monitor}
Collects records of software and user activities.\\[4pt]
\textbf{Design decision:} Define centralized transport, integrity and review cadence.\\[3pt]
\textbf{Verification evidence:} Incident reconstruction from sampled events.\\[3pt]
\sourceRef{11}{322}
\Needspace{7\baselineskip}\subsection{Traffic Monitor}
Collects network traffic metrics for diagnostics and analysis.\\[4pt]
\textbf{Design decision:} Pick coverage, aggregation and baseline thresholds.\\[3pt]
\textbf{Verification evidence:} Load baseline versus detected anomaly evidence.\\[3pt]
\sourceRef{11}{323}
\Needspace{7\baselineskip}\subsection{Data Loss Protection Monitor}
Tracks events relevant to data exposure and protection controls.\\[4pt]
\textbf{Design decision:} Connect observed events to response and DLP policy state.\\[3pt]
\textbf{Verification evidence:} Triggered test incident recorded to closure.\\[3pt]
\sourceRef{11}{323}

\begin{workbox}[title={Evaluation task}]
