# Vector Diagram Outputs (SVG)

Rendered SVG counterparts for the PlantUML sources in the [parent diagrams collection](../README.md). This directory contains `balance-and-simulation.svg`, `content-pipeline.svg`, `runtime-context.svg`, and `telemetry-trust-boundaries.svg`.

The `.puml` sources in the parent directory remain authoritative. Regenerate these assets through the repository's PlantUML rendering workflow rather than editing SVGs manually.
