\section{Purpose and source boundary}
Book-aligned topic: the six core questions of playtesting in Chapter 28. Consent mechanics, measurements, ownership, classification, and evidence handling are supplementary implementation guidance.


\section{Step 1: Data integrity}
Do not silently merge observations and inferred emotions. Keep original timestamped notes and analysis provenance.

Exit evidence: dated, attributable process record and a verification link or explicit reason for omission.


\section{Step 2: Coding}
Code issues as comprehension, control, feedback, balance, motivation, accessibility, content, social safety, or technical defect.

Exit evidence: dated, attributable process record and a verification link or explicit reason for omission.


\section{Step 3: Priority}
Combine user impact, safety, reproducibility, confidence, scope, and cost. Severe one-off incidents may override frequency.

Exit evidence: dated, attributable process record and a verification link or explicit reason for omission.


\section{Step 4: Decision}
For each finding, identify a concrete design change and a follow-up test designed to challenge the new hypothesis.

Exit evidence: dated, attributable process record and a verification link or explicit reason for omission.


\section{Step 5: Report}
Provide audience, sample method, build, task completion definition, positive/negative findings, exclusions, and confidence limits.

Exit evidence: dated, attributable process record and a verification link or explicit reason for omission.


\section{Step 6: Retention}
Honor the consent and retention plan; avoid raw personal data in repositories and demonstrations.

Exit evidence: dated, attributable process record and a verification link or explicit reason for omission.


\section{Required controls}
\begin{itemize}
\item Reproducible build and hardware record
\item Valid opt-in consent and participant withdrawal mechanism
\item Event log separating observation, quote, inference, and recommendation
\item Documented safety stop and accessibility accommodation procedure
\item Finding priority register with reviewer and re-test date
\end{itemize}

\section{Process scorecard}
Score each control as Complete, Partial, Not Demonstrated, or Not Applicable (with rationale). Do not convert absent participant evidence into an automatic pass.
