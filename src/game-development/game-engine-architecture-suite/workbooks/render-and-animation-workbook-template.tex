\section{Purpose and use}
This is the guided version of the form. For each numbered field, use the accompanying prompt to capture evidence. Leave no required criterion unsubstantiated; cite test IDs and measured data rather than subjective claims.

\subsection{Scene and coordinate conventions}
Guidance: Units, handedness, depth range, matrix convention, skeleton topology.

\WritingBox{1.05in}
\subsection{Asset and shader assumptions}
Guidance: Triangles, pixels, joints, clips and source/cooked formats.

\WritingBox{1.05in}
\subsection{Rendering correctness}
Guidance: Depth/coverage reference images, tolerances and visual diffs.

\WritingBox{1.05in}
\subsection{Animation correctness}
Guidance: Clip sampling, interpolation, event markers and root motion.

\WritingBox{1.05in}
\subsection{Measurements}
Guidance: CPU/GPU phase timings, memory, draw batches and skinning cost.

\WritingBox{1.05in}
\subsection{Negative cases}
Guidance: Degenerate triangle, missing joint, looping boundary and invalid quaternion.

\WritingBox{1.05in}
\subsection{Disposition}
Guidance: Evidence for release or additional tests.
