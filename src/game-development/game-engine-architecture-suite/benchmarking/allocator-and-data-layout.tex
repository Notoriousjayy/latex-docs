\SuiteHeading{Allocator and Data Layout Benchmark Procedure}{Benchmark procedure}{Evidence protocol}
\section{Objective and conditions}
Procedure: benchmark original laboratory implementations under repeatable test conditions. Treat each measurement as a property of the exact workload and environment; any comparison across hosts must state its limitations.

\subsection{Experiment}
Compare a standard allocation baseline, monotonic arena and cache-aware AoS/SoA loops with identical work and object sizes.

\subsection{Controls}
Warmup, random seed, compiler optimization flags, validation checksum, affinity where available and peak RSS.

\subsection{Measurement}
Report operations/s, time/operation, p95, live bytes and allocation calls; test at multiple working-set sizes.

\subsection{Safety}
Run alignment/bounds tests and sanitizer-enabled debug build separately from timed optimized runs.

\subsection{Interpretation}
Cache locality and allocation overhead are workload-specific; do not declare a universal winner.

\section{Required CSV schema}
\begin{verbatim}
experiment,revision,host,variant,seed,iteration,elapsed_ns,
work_items,peak_bytes,success,notes
\end{verbatim}\section{Report checklist}
\begin{itemize}
\item Input and output artifact hashes
\item At least one cold and warm run where applicable
\item Raw data, median and tail-percentile summary
\item Error bars or limitations for small sample sizes
\item Explicit negative tests and documented release decision
\end{itemize}
