\section{How to complete}
Rate action readability, controlled holds, expressive spacing, anticipation, weight and visual clarity. Document evidence for each score. Record the observed evidence, measurement environment, evaluator, and unresolved issues. Use 0 = unacceptable or not demonstrated; 1 = major revision; 2 = partially demonstrated; 3 = acceptable; 4 = exceeds acceptance criteria. A score is not approval without evidence.
\section{Illustrative entry}
Example: identify an animation clip, give exact frame boundaries, and describe one measurable acceptance threshold.
