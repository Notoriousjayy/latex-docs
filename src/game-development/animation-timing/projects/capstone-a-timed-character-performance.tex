\section{Project brief}
Produce a fifteen-second character pantomime with storyboard, anticipation, follow-through and deliberate mood change.\par\textbf{Source crosswalk:} Chapters 1--8, 27--46, 66--67. Source chapter concepts are applied through original technical work.
\section{Required deliverables}
\begin{enumerate}
\item A six-or-more-shot storyboard and camera continuity plan.
\item An exposure or digital timing sheet with rational time base.
\item Three before/after retimed beats with captured evidence.
\item A filled readability scorecard and peer-review revision record.
\end{enumerate}
\section{Build phases}
\begin{enumerate}
\item Proposal: fix creative intention, constraints and intended platform.
\item Prototype: demonstrate one timing mechanic and one game-action pathway.
\item Controlled comparison: vary a timing decision while holding other factors constant.
\item Validation: execute code tests, contact/timebase checks and qualitative playback review.
\item Finalization: record defects, acceptance scorecards and the defended revision.
\end{enumerate}
\section{Rubric}
\textbf{Artistic execution} 30\%; \textbf{timing reasoning} 20\%; \textbf{technical correctness} 25\%; \textbf{repeatability and measurement} 15\%; \textbf{review and accessibility} 10\%. Document scores separately rather than using a single perceived-quality number.
\section{Submission manifest}
Commit hash; engine or code runtime; assets and licensing; test commands; original source chapter references; raw metrics; render captures or equivalent; completed scorecard; release decision.
