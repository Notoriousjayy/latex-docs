\section{Purpose}
Provide a release-gate specification for authored pose quality and gameplay animation behavior. Animators approve perceptual intent, engineers approve runtime behavior, and QA records reproduction evidence. A numeric pass does not replace creative review.
\section{Test layers}
\begin{enumerate}
\item Unit: timing conversions, loop arithmetic, finite blend weights, exposure partition and deterministic spring integration.
\item Contract: clip metadata, marker units, skeleton/rig IDs, coordinate conventions and content revisions.
\item Integration: controller interruptions, root displacement ownership, contact lock, camera-relative motion and transitions.
\item End-to-end: input-to-visible-cue latency, accessibility options, audiovisual synchronization and real device playback.
\item Regressions: captured trace parity and frame-strip comparison under fixed seed and scene.
\end{enumerate}

\section{Release evidence and decision}
Attach exact build and rig revision, target hardware, test artifact URI, test author, date, thresholds, measured values, unresolved defects, and sign-off. False passes from mocked or missing telemetry must be reported as unverified.
