# Game Design Engineering: Data Catalog

Machine-readable CSV indexes belonging to the [Game Design Engineering suite](../README.md). These are navigational crosswalks, not standalone design approvals or source-book reproductions.

| Dataset | Purpose |
|---|---|
| [Artifact manifest](artifact-manifest.csv) | Inventory of learning and engineering artifacts |
| [Chapter-to-artifact crosswalk](chapter-to-artifact-crosswalk.csv) | Map source chapters to the suite's document outputs |
| [Lens-to-chapter index](lens-to-chapter-index.csv) | Search the game-design lens index by chapter |

Keep these CSV files aligned with their owning documentation and validate relative links when changing them.
