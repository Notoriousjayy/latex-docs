\section{Expected value and variance}
For outcomes $x_i$ with probabilities $p_i$, $E[X]=\sum_i p_ix_i$ and $\mathrm{Var}(X)=\sum_i p_i(x_i-E[X])^2$. Expected values do not capture risk preference, learning curve, or perceived fairness.

\section{Reward economies}

\section{Monte Carlo evaluation}
For $N$ independent runs and estimated win rate $\hat p$, standard error is approximately $\sqrt{\hat p(1-\hat p)/N}$. Verify the sampling model and report seeds, sample counts, and interval assumptions.
