\section{Scenario and learning objective}
Use the small Java library with Maven and JUnit. Distinguish lifecycle validation, compilation, test, packaging and artifact promotion.

\section{Prerequisites}
Complete prerequisite modules identified by the curriculum. Use a disposable teaching repository or sandbox. Tool versions and network access must be recorded; example workflows are intentionally inert until copied into the target repository.

\section{Execution protocol}
\begin{enumerate}
\item Run mvn -B -ntp verify twice, remove target, re-run and compare cold and warm dependency-resolution times.
\item Record a clean starting revision, operating system, runner, tool versions, env flags and dependency locks.
\item Execute baseline commands and collect console output plus machine-readable result.
\item Introduce the specified fault or policy denial; observe expected failing exit/status.
\item Restore the system to a clean revision and reproduce the passing state.
\item Explain the confidence gained, possible false negatives, and remaining threats.
\end{enumerate}
\section{Acceptance gate}
Maven test discovers the JUnit tests and fails when the function implementation is wrong.

\begin{itemize}
\item A reviewer can reproduce both pass and fail pathways.
\item Logs are scrubbed of tokens, PII, internal endpoints and environment identifiers.
\item Metrics and status references identify their source revision.
\item A decision record explains any policy exception and its expiry.
\end{itemize}
\section{Deliverables}
\begin{itemize}
\item Commit/PR and reproducible command transcript.
\item Test results, failure evidence, and issue or remediation record.
\item Completed companion laboratory workbook and assessment scorecard.
\item One architecture or risk-control improvement with rationale.
\end{itemize}
\section{Debrief}
\begin{itemize}
\item Did the earliest relevant gate detect the injected fault?
\item What hidden input would invalidate reproducibility?
\item Can a low-trust event obtain privileged credentials or release artifacts?
\item How would this scale to independent application repositories?
\end{itemize}
