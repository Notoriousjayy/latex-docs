\section{Provenance and scope}
The book is a 2007 foundational source. Its chapter structure is preserved only as a study mapping; all original material in this package is newly written. Modern GitHub Actions execution, current supply-chain controls, SLSA v1.2, cloud OIDC and the assessment rubrics are not attributed to the book. Validate current platform capabilities when deploying.
