\section{Status and scope}
Proposed reference architecture. No production cloud environment or organizational authorization is implied. Illustrative diagrams reside in this suite and should be verified against the actual runner, GitHub and cloud trust configuration.

\section{Context and stakeholders}
Application developers, maintainers, security reviewers, build platform operator and release approvers. Source, workflow files and pull requests are untrusted to varying degrees; GitHub-hosted runner is temporary compute, not an approval authority.

\section{Components and ports}
Source repository emits PR and push events. Runner fetches known SHA, builds language-specific projects, emits JUnit/coverage/results, captures artifact digest and report reference. Policy enforces required checks; protected release workflow consumes only approved artifacts.

\section{Trust boundaries}
PR can modify code and workflow text and executes in read-only context; merge gate provides protected branch policy; deployment runner uses distinct environment, role and `id-token: write`. Untrusted artifacts and caches must not cross to privileged execution without verification.

\section{Availability and recovery}
Timeouts bound stuck jobs; retries are limited and classified, not used to suppress failing assertions. Rollback deployment failure cannot repair a broken source branch by itself.

\section{Architecture fitness functions}
A changed SHA invalidates previous green status; privileged job cannot trigger on an untrusted PR; every release candidate maps to one digest; a failed required gate prevents production promotion.

\section{Acceptance review}
\begin{itemize}
\item Record context, container/module responsibilities and owning teams.
\item Identify untrusted inputs and every elevation or data transfer.
\item Exercise one successful path and at least one deliberate unauthorized path.
\item Identify release restoration point and hard-stop thresholds.
\item Attach reviewer sign-off and an architecture decision record for nontrivial trade-offs.
\end{itemize}
