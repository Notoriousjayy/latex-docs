\section{Assessment rules}
This is an original educational maturity model and is not a formal industry certification. Score seven independent dimensions 0--4, only where evidence shows the full level. Do not average away a severe gap in credential or production authorization controls.

\section{Level rubric}
\begin{itemize}
\item 0 Ad hoc: controls absent or unowned.
\item 1 Repeatable: manual control and local knowledge; inconsistent evidence.
\item 2 Defined: repository policy and documented procedures; execution reasonably consistent.
\item 3 Enforced: automated required gates and reviewable artifacts; exceptions controlled.
\item 4 Measured: monitored efficacy, reliability and security trends; systematic improvement.
\end{itemize}
\section{Integration discipline}

\section{Decision and remediation}
Record scores in the matched scorecard. Report minimum dimension, median dimension, risk exceptions and evidence gaps separately. For any critical authorization failure, mark release not approved regardless of average score. Assign an owner and next verification date to every improvement.

\section{Independent quality review}
\begin{itemize}
\item All mandatory dimensions have raw evidence links.
\item Reviewer inspected failure and unauthorized paths.
\item No scores based solely on future plans.
\item Risks and debt are registered with deadlines.
\item Decision has an accountable signature.
\end{itemize}
