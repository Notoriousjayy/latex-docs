\section{How to use this curriculum}
Dependency edges are strict prerequisites: a learner advances only after demonstrating gate evidence, not after consuming reading material. Recommended learning order is listed below and is independent of a fixed calendar.

\section{Placement of book material}
Book chapters anchor the conceptual portions of M01--M06, M08 and M09; workflow syntax, security hardening, SLSA, DORA and modern deployment mechanics are clearly supplemental.

\section{M00: Git and local toolchains}
Prerequisite modules: none.

Knowledge and practice: Git checkout, branch, review; Python, Maven, CMake; clean shell execution.

Gate evidence: Demonstrate a repeatable local build and explain version identity..

Required review: instructor or peer reproduces a pass and a controlled failure; unverified screenshots without run identity do not satisfy completion.

\section{Capstone evaluation}
\begin{itemize}
\item All three language builds succeed from clean checkouts.
\item CI default permissions and privilege escalation are reviewed.
\item Pull request jobs cannot reach deployment credentials.
\item A failed gate demonstrably blocks candidate promotion.
\item One artifact is identified consistently by its digest.
\item Maturity scores cite evidence and owners, not aspirations.
\end{itemize}
