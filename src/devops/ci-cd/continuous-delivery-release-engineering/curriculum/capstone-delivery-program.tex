\section{Capstone charter}
Design and demonstrate a safe continuous-delivery system for a small service. A repository commit shall produce a uniquely identified candidate, pass deterministic tests and risk gates, and be eligible for protected sandbox deployment and rollback.


\section{Required demonstrators}
\begin{enumerate}
\item A fast deterministic CI build and test with a deliberate red-build demonstration.
\item Immutable artifact, SHA256 verification and a promotion manifest.
\item OIDC-based AWS authentication with scoped trust and a manually gated protected environment.
\item Terraform validate/plan; isolated sandbox apply only after human approval; teardown procedure.
\item API and schema compatibility tests, performance thresholds, and negative-case evidence.
\item One simulated canary failure and an independently confirmed recovery.
\item Deployment audit trail and at least two metrics with baseline and acceptance ranges.
\end{enumerate}

\section{Acceptance rubric (100 points)}
\begin{itemize}
\item Pipeline integrity and provenance: 20
\item Quality engineering and negative tests: 15
\item Cloud IAM and policy enforcement: 20
\item Data and reversible release plan: 15
\item Observability/benchmarks: 10
\item Documentation, traceability and evidence: 15
\item Operational demonstration and peer review: 5
\end{itemize}

\section{Disqualifying safety defects}
\begin{itemize}
\item Cloud credentials committed to source or available to untrusted pull request runs.
\item A production-equivalent apply without isolated state and explicit authorization.
\item No documented recovery route for destructive schema/data changes.
\item Evidence fabricated rather than captured from actual runner executions.
\end{itemize}

\section{Submission package}
\begin{itemize}
\item Source commit and run identifiers; review history
\item Architecture view, ADR and exception register
\item Pipeline artifact checksums, scan findings and promotion record
\item Test report, performance baseline and rollback record
\item Completed architecture scorecard and improvement backlog
\end{itemize}
