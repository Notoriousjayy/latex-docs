\section{Toolchain selection happens before compiler detection}
The \texttt{CMAKE\_TOOLCHAIN\_FILE} variable is a configuration input. CMake caches compilers and ABI detection results in its binary directory. Emscripten's \texttt{emcmake} wrapper supplies its toolchain file; the reference uses \texttt{CMakePresets.json} to make the choice explicit. The WASI SDK provides distinct files for Preview 1, Preview 2, Preview 3, and experimental Preview 1 threads.

\section{Dependency reproducibility tiers}
\begin{enumerate}
\item \textbf{Declared}: versions recorded in a manifest but without artifact hashes.
\item \textbf{Resolved}: versions, target triples, flags, and transitive dependencies locked.
\item \textbf{Authenticated}: resolved archives checked against trusted signed digests or provenance.
\item \textbf{Reproducible}: hermetic inputs, normalized paths/timestamps, deterministic archives, and independent rebuild comparison.
\end{enumerate}
Disallow \texttt{latest}, floating branch refs, unreviewed \texttt{FetchContent} URLs, and untrusted network downloads in a production promotion job. Keep host and guest dependency graphs separate and produce one SBOM per platform artifact.

\section{Cross-compilation diagnostics}
Inspect the configured toolchain and imported package locations:
\begin{lstlisting}[language=bash]
cmake -LAH -N build/native
# Inspect CMAKE_CXX_COMPILER, CMAKE_SYSTEM_NAME,
# and CMAKE_FIND_ROOT_PATH.
\end{lstlisting} In WASI configurations, host tools should come from the host PATH while linked libraries/includes come from the target sysroot. Never force a host executable into a cross-target \texttt{try\_run} test: use compile-only tests, a genuine target runtime, or an explicit cached result with an audit note.

\section{Upgrade playbook}
\begin{enumerate}
\item Open an SDK upgrade ADR specifying feature changes, CVEs, and compatibility risks.
\item Update the version manifest and immutable binary/download digests together.
\item Rebuild all three profiles from clean directories, including all dependencies.
\item Compare unit vectors, expected imports/exports, size, and runtime performance.
\item Review attestation metadata, then promote the pinned baseline in one version-control change.
\end{enumerate}
