\section{Migration workstreams}
\begin{enumerate}
\item \textbf{Inventory.} Map CMake global settings, native dependencies, system calls, threads, CPU intrinsics, C++ exception requirements, and plugin ABI assumptions.
\item \textbf{Partition.} Extract portable core; add adapter interfaces and deterministic tests. Remove direct OS headers from the core graph.
\item \textbf{Native reference.} Add independent native preset, unit/golden vectors, sanitizer job, and expected output contract.
\item \textbf{Browser MVP.} Integrate Emscripten toolchain, exports, JS wrapper, loading policy, CSP, and Node smoke test; add real-browser E2E later.
\item \textbf{WASI MVP.} Compile Preview 1 command; validate runtime launch with no preopens. Introduce Preview 2 only when interoperability requires WIT components.
\item \textbf{Release hardening.} Lock SDKs, dependencies, download hashes, action revisions; generate SBOMs, test evidence, and provenance.
\item \textbf{Operationalize.} Performance baselines, escalation procedures, vulnerability management, patching cadence, rollback, and support owners.
\end{enumerate}

\section{Ownership and governance}
\begin{itemize}
\item \textbf{Build engineer:} presets, compiler flags, dependency target resolution, SDK upgrade compatibility.
\item \textbf{Runtime owner:} Wasmtime configuration, host imports, capability review and resource limits.
\item \textbf{Web engineer:} JS wrapper, bundler integration, CSP, Web Worker policy, real browser E2E.
\item \textbf{Application security:} threat modeling, SAST, dependency findings, fuzz/negative tests, release security gates.
\item \textbf{Release engineer:} manifests, SBOM, attestation verification, signing identities, deployment/rollback.
\end{itemize}

\section{Troubleshooting decision tree}
\begin{enumerate}
\item CMake finds wrong compiler? Delete only that preset's cache, activate SDK, and reconfigure.
\item Browser has undefined export? Inspect function linkage and Emscripten export flags; verify exact generated symbol.
\item Browser module loads but hangs? Check async instantiation, CSP, MIME type, missing \texttt{.wasm}, worker isolation and runtime errors.
\item WASI module fails at startup? Inspect WASI preview and imports, runtime compatibility, and capability policy.
\item CI reports missing artifact? Compare binary suffixes, bundler outputs, working directory, and manifest patterns.
\item Provenance verification fails? Check expected issuer, repository, workflow identity, attested digest, and asset version.
\end{enumerate}
