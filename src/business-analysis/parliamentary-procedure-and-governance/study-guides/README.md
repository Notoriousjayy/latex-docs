# Section-by-section study guides

Each of the 63 source sections has an independently authored, standalone LaTeX study guide (`section-XX-*.tex`). Read in numeric order or follow the prerequisite curriculum. Section identifiers refer to *RONR*, 12th ed., not to the PDF page index. Every guide contains outcomes, a conceptual synthesis, a procedure, a scenario, a control against a common error, and assessment questions. The guides do not reproduce the book and are not official parliamentary interpretations.
