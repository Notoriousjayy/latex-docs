\section{Scenario and initial inputs}
Backlog candidate sizes: submit request 5, view own status 3, attach file 5, approve request 8, audit search 8, notify requester 3 (illustrative points). Historical accepted-point totals are 10, 13, 11, and 12.

\section{Procedure}
\begin{enumerate}[leftmargin=*,itemsep=3pt]
\item Explain the estimation basis and identify uncertainty in approve request.
\item Compute the average and range of historical accepted throughput.
\item Select a coherent iteration goal with no more than 11 points of estimated stories.
\item Break selected stories into engineering and verification tasks.
\item Describe what to do if one story remains incomplete at iteration end.
\end{enumerate}
\section{Submission checklist}
\begin{itemize}[leftmargin=*,itemsep=2pt]
\item A worked estimate rationale
\item One iteration plan with an explicit goal
\item An incomplete-work disposition
\end{itemize}
\section{Verification criteria}
\begin{itemize}[leftmargin=*,itemsep=2pt]
\item Outputs describe user outcomes rather than only technical activity.
\item Evidence is sufficient for another practitioner to reproduce or challenge the work.
\item Security, negative behavior and assumptions are visible when relevant.
\item Explicit tradeoffs and decision rights appear in the results.
\end{itemize}
\begin{tcolorbox}[colback=amberback,colframe=navy,title={Instructor note / expected reasoning},breakable]
Expected throughput mean = 11.5 points; do not count partial completion as accepted points.

\end{tcolorbox}
\section{Stretch exercise}
Exchange artifacts with another participant. Identify one unverifiable expectation, one dependency hidden by the initial plan, and one incomplete traceability link. Revise the record and document what changed.
