\section{Scenario and initial inputs}
A new department has a manual email-based service request process. It wants a low-risk request submission and review portal deployed in three short iterations, with explicit cross-user access controls.

\section{Procedure}
\begin{enumerate}[leftmargin=*,itemsep=3pt]
\item Interview or role-play two user types and capture evidence tiers.
\item Create an outcome statement, role model and 12-story candidate backlog.
\item Apply INVEST, vertical slicing and relative estimation to planned items.
\item Construct a two-scenario release plan with measurable assumptions.
\item Produce 12 acceptance examples including denied access, invalid data and operational failure.
\item Create a change-impact exercise, scorecards and a release readiness record.
\item Conduct a final demo where an independent evaluator identifies missing evidence.
\end{enumerate}
\section{Submission checklist}
\begin{itemize}[leftmargin=*,itemsep=2pt]
\item Role model and goals
\item 12-story backlog with sizing
\item 12 acceptance scenarios and tests
\item Release plan and risk register
\item Traceability and review decision
\end{itemize}
\section{Verification criteria}
\begin{itemize}[leftmargin=*,itemsep=2pt]
\item Outputs describe user outcomes rather than only technical activity.
\item Evidence is sufficient for another practitioner to reproduce or challenge the work.
\item Security, negative behavior and assumptions are visible when relevant.
\item Explicit tradeoffs and decision rights appear in the results.
\end{itemize}
\begin{tcolorbox}[colback=amberback,colframe=navy,title={Instructor note / expected reasoning},breakable]
The capstone passes only when real behavior can be demonstrated, failures are visible and a product decision owner can authorize acceptance.

\end{tcolorbox}
\section{Stretch exercise}
Exchange artifacts with another participant. Identify one unverifiable expectation, one dependency hidden by the initial plan, and one incomplete traceability link. Revise the record and document what changed.
