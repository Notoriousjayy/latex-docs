# C secure coding example

An isolated, defensive implementation of bounded memory copying for the C/C++ laboratory.

| File | Purpose |
|---|---|
| [safe_copy.c](safe_copy.c) | C example for size checks and safe copy operations |

Use only synthetic inputs. Compile with a modern C compiler and enable warnings and sanitizers when supported. See [laboratories](../../labs/README.md) and the [suite index](../../README.md).
