# Application Security Review Processes

## Overview

This collection contains the application-security assessment operating model, reusable review records, working papers, coverage and finding-analysis instruments, and process diagrams.

## Template and Blank variants

| Artifact | Purpose |
|---|---|
| [Application Review Analysis Template](application-review-analysis-template.tex) | Authoring and methodological reference. Includes the adaptive review loop and guidance for completing the engagement, coverage, findings and remediation sections. |
| [Application Review Analysis Blank](application-review-analysis-blank.tex) | Unfilled assessment workbook retaining engagement controls, scopes, traceability, technical finding analysis and closeout worksheets without the introductory operating-model diagram. |

The **Blank** is not a completed source-code assessment. Document scope, authorization, evidence, review dates and responsible approvers explicitly. Do not infer security status or compliance from an empty checklist. This workbook supports authorized review and does not replace independently verified findings.

## Other sources

See [modern application security assessment](modern-application-security-assessment.tex) for broader technical context and assessment approaches. Supporting process diagrams remain in their existing subdirectories.

## Validation

Compile using the repository's supported LaTeX build system. The pair validator checks source paths and matching section hierarchy, but cannot establish the correctness of review findings.
