\section{Control catalog operating model}
\begin{enumerate}
\item Identify the risk(s), assets, expected outcome and selected control; map to the SoA.
\item Design the control with trigger, input, responsible operator, decision rule, output, retention and failure handling.
\item Collect independent operating evidence over a relevant period, including exceptions and failure paths.
\item Test design adequacy and actual operation; trace deviations to tracked remedial actions.
\item Review changes in scope, threats and suppliers to revise applicability or design.
\end{enumerate}
