\clearpage
\section{M0 Baseline}
Inventory existing suite, API reference versions, permissions and PR-block root causes; classify file changes and record baseline SHA. Gate: reviewers accept coverage limitations.


\section{M1 Architecture}
Finalize interfaces, E1/E2/E3 semantics, AD/AVS and ADR proposals; threat-model all boundaries. Gate: technical and AppSec review.


\section{M2 Read-only discovery}
Collect metadata using least-privilege app, paginate correctly, preserve denied/truncated states; test with synthetic replay. Gate: zero write permission and coverage report.


\section{M3 Policy evaluation}
Implement deterministic offline decisions with immutable version and negative tests. Gate: no unknown yields ALLOW\_MERGE; independent approvals required.


\section{M4 Synthetic dry-run}
Simulate delegated requests and exception expiry; demonstrate idempotency and TOCTOU revalidation. Gate: read-only network and synthetic datasets.


\section{M5 Approval design}
Verify API contract, reviewer role, separation of duties, audit chain and rollback. Gate: security signoff before privileged application work.


\section{M6–M7 Validation and pilot}
Complete threat-model tests; pilot with nonproduction repository using shadow-mode and human decisions. Gate: documented zero unauthorized changes, acceptable error rate and latency.


\section{M8 Production approval}
Require change control, independent risk review, explicit organization authorization, feature license and scope verification. Gate: approved production rollout and disable switch.


\section{M9 Continuous improvement}
Track P50/P95 waits, invalid dispositions, exception expiry, dismissed/reopened counts and policy drift. Review with AppSec and engineering; maintain backlog.


\section*{Document status and provenance}
This document is a proposed reference design. Actual GitHub feature availability, organization policies, approvals, and runtime performance must be independently verified before adoption. The architecture inventory is not proof of vulnerability exploitability or correctness of a dismissal.
