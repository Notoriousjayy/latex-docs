# Deterministic Printable Grammar Fragments

The five LaTeX fragments here are generated from the pinned JSON data by the [repository script](../../../../../tooling/scripts/generate_syntax_references.py). They are not standalone document roots. Run the script in check mode to verify reproducibility, then compile the five parent language reference documents. Non-ASCII glyphs are displayed as printable Unicode codepoint labels, while JSON preserves source UTF-8.
