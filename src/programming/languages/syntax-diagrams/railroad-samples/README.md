# Native PlantUML EBNF Railroad Diagrams

Five illustrative diagrams are authored in PlantUML EBNF. They are rendered through the existing pinned renderer. PNG is the authoritative display asset for both GitHub Pages and the PDF documents; the pipeline may also generate SVG for its existing artifact contract. This folder does not claim one-to-one visual parity with all 1,164 original diagram factories. The published static gallery references only verified PNGs.
