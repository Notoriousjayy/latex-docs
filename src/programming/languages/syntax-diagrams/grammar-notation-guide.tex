\section{Purpose and scope}
This reference explains how grammar notations are read and why visual
syntax diagrams cannot, by themselves, prove complete language conformance.
The five associated language references preserve production text from
pinned source repositories and use the project's existing pdfLaTeX
and pinned PlantUML rendering infrastructure.

\section{BNF}
A context-free grammar describes a set of productions with
nonterminals, terminal symbols, a start symbol, and alternative derivations.
Backus--Naur Form represents productions using symbolic nonterminals and
alternatives. A grammar recognizes a syntactic language, not all typing
rules, name binding, contextual keywords, or execution semantics.

\section{EBNF}
Extended Backus--Naur Form adds shorthand for repetitions, optional terms,
grouping, and alternatives. Exact metasymbol conventions vary by source;
do not silently reinterpret a language standard's native grammar as ISO EBNF.
In a common ISO-style notation, curly braces express repetition, square
brackets express optional items, vertical bars express alternation,
and commas express concatenation.
\begin{lstlisting}
identifier = letter, {letter | digit};
letter = "a" | "b" | "c";
digit = "0" | "1";
\end{lstlisting}

\section{PEG}
Parsing expression grammars use ordered choice rather than the
unordered alternative associated with conventional context-free grammars.
Lookahead, cuts, and parsing actions can affect acceptance and evaluation.
Python's PEG-based grammar cannot be assumed equivalent to an EBNF
transcription or a railroad diagram, even when the names match.

\section{Railroad diagrams}
A syntax (railroad) diagram typically depicts a start point, terminal
and nonterminal nodes, sequential paths, alternatives, and optional or
repeated loops. The graph conveys derivational routes; it generally omits
lexical goals, contextual restrictions, static semantics, and semantic
actions. A displayed grammar branch must therefore be checked against the
pinned language specification before being treated as normative.

\section{Reproducible rendering architecture}
The authored reference documents and grammar transcriptions compile
with pdfLaTeX. The curated EBNF diagrams are maintained as
\texttt{.puml} files using \texttt{@startebnf} and are rendered by the
repository's existing, version-pinned PlantUML pipeline into PNG and SVG.
The PDF includes the PNG when present and retains a source pointer while
the render job has not yet generated an image.
No web application, browser runtime, npm dependency, or secondary GitHub
Pages deployment is introduced.

\section{Source limitations and licensing}
The source repositories describe MIT licensing in their READMEs.
Review upstream terms and appropriate attribution prior to redistribution.
The original TypeScript grammar factory modules are stored as inert
\texttt{.txt} migration evidence. They are not imported by the build.
Text representations and rendered diagrams are technical companions,
not certified reproductions of the normative standards.
