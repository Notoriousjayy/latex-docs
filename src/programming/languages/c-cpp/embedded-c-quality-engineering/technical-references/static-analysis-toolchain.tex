\section{Verification layers}
\begin{enumerate}
\item Text and formatter hygiene.
\item Compiler diagnostics and header self-containment.
\item Static analyzer with versioned checker configuration.
\item Host unit tests, property tests and sanitizers.
\item Human and hardware-in-the-loop verification for timing, ISR and peripheral behavior.
\end{enumerate}

\section{Finding triage}
\begin{enumerate}
\item Record source revision, checker and command.
\item Assess reachable inputs, impact and target conditions.
\item Demonstrate reproduction or a justified false positive.
\item Fix or obtain time-bounded approval with compensating controls.
\item Retest on subsequent changes.
\end{enumerate}

\section{Tool calibration}
Use an isolated known-bad fixture to verify that each critical release check can fail. Scanners do not prove electrical correctness, ISR timing or complete absence of defects.
