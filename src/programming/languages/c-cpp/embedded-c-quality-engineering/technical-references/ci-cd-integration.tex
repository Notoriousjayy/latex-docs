\section{Proposed pipeline stages}
\begin{enumerate}
\item Least-privilege source checkout and text hygiene.
\item Documented warning-clean host build.
\item Positive, negative and boundary unit tests.
\item Static analysis with raw report retention.
\item Target build and hardware verification where applicable.
\item Independent review, exceptions and release decision.
\end{enumerate}

\section{Quality gate contract}
\begin{itemize}
\item Missing tools or swallowed exit codes must fail closed.
\item A known-bad isolated fixture must produce the expected failure.
\item Hardware and concurrency claims are verified beyond host CI.
\item Production actions should be pinned to reviewed immutable revisions.
\end{itemize}

\section{Location of inactive example}
The workflow under examples/workflows is deliberately outside the active .github/workflows directory. Before reuse, pin actions, enforce least privilege, check versions and add the actual product's targets.
\section{Decision evidence}
Record build output, test outcomes, analyzer dispositions, HIL/timing results, approved deviations, artifact hashes and accountable approver.
