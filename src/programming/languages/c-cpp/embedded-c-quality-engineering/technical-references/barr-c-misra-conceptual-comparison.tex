\section{Edition boundaries}
BARR-C:2018 discusses compatibility with MISRA C:2012. MISRA C:2023 is a later edition. The copyrighted MISRA rule text and a normative rule-by-rule crosswalk are not reproduced; use a legitimately obtained edition for internal mapping.
\section{Concept-level comparison}

\section{Assessment workflow}
\begin{enumerate}
\item Identify edition and product scope.
\item Map concepts to authorized licensed rule identifiers inside a restricted workspace.
\item Separate overlap, additional style, stricter restrictions and unverified assumptions.
\item Keep checker coverage, human reviews and approved deviations distinct.
\end{enumerate}
