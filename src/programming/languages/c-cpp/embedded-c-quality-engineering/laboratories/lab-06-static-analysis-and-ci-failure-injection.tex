\section{Purpose and prerequisites}
Tool effectiveness and repeatability. Prerequisites: C99 compiler, terminal, Git, access to an isolated test workspace and familiarity with the referenced study guide. This exercise is a proposed teaching protocol.
\section{Implementation specification}
\begin{enumerate}
\item Compile the baseline with strict C99 warnings and unit tests.
\item Run a configured static analyzer and retain the exact invocation and version.
\item On a disposable isolated fixture, inject an out-of-bounds read, confirm check failure and remove fixture.
\item Reconcile findings to source lines, risk, disposition and owner.
\end{enumerate}

\section{Test matrix}
\begin{itemize}
\item Construct an explicit oracle for clean baseline; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for known-bad injected fixture; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for missing checker binary; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for scanner error exit; record the input, expected return, observed result and environment.
\end{itemize}

\section{Execution and evidence}
\begin{enumerate}
\item Create an isolated source revision and record compiler, flags, architecture and optimization.
\item Run unit tests with positive, negative and boundary conditions; preserve complete output.
\item Run applicable compiler or SAST checks; distinguish tool-detected defects from manual review.
\item Record the source-to-test trace and an independent reviewer disposition.
\end{enumerate}

\section{Acceptance criteria}
A missing scanner and known-bad fixture both fail closed, and each retained issue has a traceable disposition.

\textbf{Control alignment:} EC-Q07 and EC-Q08.
\section{Failure analysis}
For any failed check, provide a minimized reproducer, causal explanation, correction, retest and residual risk. Never silently treat an analysis-tool outage as a pass.
\section{Artifact checklist}
\begin{itemize}
\item Source and build recipe
\item Test cases and expected-versus-observed results
\item Tool versions and raw diagnostics
\item Security/portability caveats
\item Reviewer signature and corrective-action link
\end{itemize}
