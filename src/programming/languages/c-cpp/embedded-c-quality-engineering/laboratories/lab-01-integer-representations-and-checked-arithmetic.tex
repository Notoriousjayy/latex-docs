\section{Purpose and prerequisites}
Numeric overflow and promotions. Prerequisites: C99 compiler, terminal, Git, access to an isolated test workspace and familiarity with the referenced study guide. This exercise is a proposed teaching protocol.
\section{Implementation specification}
\begin{enumerate}
\item Implement a checked addition of two byte counts without overflow.
\item Decode big-endian 16-bit unsigned values without assuming host endianness.
\item Audit every signed/unsigned comparison and document the conversion invariant.
\end{enumerate}

\section{Test matrix}
\begin{itemize}
\item Construct an explicit oracle for zero + zero; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for maximum valid sum; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for sum greater than SIZE\_MAX; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for signed negative converted incorrectly; record the input, expected return, observed result and environment.
\end{itemize}

\section{Execution and evidence}
\begin{enumerate}
\item Create an isolated source revision and record compiler, flags, architecture and optimization.
\item Run unit tests with positive, negative and boundary conditions; preserve complete output.
\item Run applicable compiler or SAST checks; distinguish tool-detected defects from manual review.
\item Record the source-to-test trace and an independent reviewer disposition.
\end{enumerate}

\section{Acceptance criteria}
The implementation rejects representational overflow before performing arithmetic and has two deliberately failing fixtures that prove the check detects defects.

\textbf{Control alignment:} EC-Q02 and EC-Q03.
\section{Failure analysis}
For any failed check, provide a minimized reproducer, causal explanation, correction, retest and residual risk. Never silently treat an analysis-tool outage as a pass.
\section{Artifact checklist}
\begin{itemize}
\item Source and build recipe
\item Test cases and expected-versus-observed results
\item Tool versions and raw diagnostics
\item Security/portability caveats
\item Reviewer signature and corrective-action link
\end{itemize}
