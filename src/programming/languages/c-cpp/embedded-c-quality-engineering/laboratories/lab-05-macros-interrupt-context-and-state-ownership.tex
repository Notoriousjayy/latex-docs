\section{Purpose and prerequisites}
ISR reentrancy and execution budget. Prerequisites: C99 compiler, terminal, Git, access to an isolated test workspace and familiarity with the referenced study guide. This exercise is a proposed teaching protocol.
\section{Implementation specification}
\begin{enumerate}
\item Replace an unsafe MIN macro with an appropriate typed C99 static inline function.
\item Design an ISR-facing event protocol with declared shared state ownership.
\item Record the critical section or atomicity assumption for the actual target hardware.
\end{enumerate}

\section{Test matrix}
\begin{itemize}
\item Construct an explicit oracle for increment-expression macro call; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for interrupt during read; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for event queue full; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for device reset during pending event; record the input, expected return, observed result and environment.
\end{itemize}

\section{Execution and evidence}
\begin{enumerate}
\item Create an isolated source revision and record compiler, flags, architecture and optimization.
\item Run unit tests with positive, negative and boundary conditions; preserve complete output.
\item Run applicable compiler or SAST checks; distinguish tool-detected defects from manual review.
\item Record the source-to-test trace and an independent reviewer disposition.
\end{enumerate}

\section{Acceptance criteria}
Host test captures macro side-effect failure; target integration documents worst-case ISR timing and synchronization.

\textbf{Control alignment:} EC-Q06.
\section{Failure analysis}
For any failed check, provide a minimized reproducer, causal explanation, correction, retest and residual risk. Never silently treat an analysis-tool outage as a pass.
\section{Artifact checklist}
\begin{itemize}
\item Source and build recipe
\item Test cases and expected-versus-observed results
\item Tool versions and raw diagnostics
\item Security/portability caveats
\item Reviewer signature and corrective-action link
\end{itemize}
