\section{Purpose and prerequisites}
Control flow and state validity. Prerequisites: C99 compiler, terminal, Git, access to an isolated test workspace and familiarity with the referenced study guide. This exercise is a proposed teaching protocol.
\section{Implementation specification}
\begin{enumerate}
\item Define explicit states WAIT\_START, READ\_LEN, READ\_BODY, READ\_CRC, COMPLETE and ERROR.
\item Specify an input byte budget and a clear transition for an unknown state.
\item Check invariants at each transition and reset the parser without stale state.
\end{enumerate}

\section{Test matrix}
\begin{itemize}
\item Construct an explicit oracle for zero bytes; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for invalid state injection; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for oversized length; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for back-to-back frames; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for max bounded processing steps; record the input, expected return, observed result and environment.
\end{itemize}

\section{Execution and evidence}
\begin{enumerate}
\item Create an isolated source revision and record compiler, flags, architecture and optimization.
\item Run unit tests with positive, negative and boundary conditions; preserve complete output.
\item Run applicable compiler or SAST checks; distinguish tool-detected defects from manual review.
\item Record the source-to-test trace and an independent reviewer disposition.
\end{enumerate}

\section{Acceptance criteria}
All paths terminate within a bounded number of iterations, and invalid state produces a deterministic error.

\textbf{Control alignment:} EC-Q05.
\section{Failure analysis}
For any failed check, provide a minimized reproducer, causal explanation, correction, retest and residual risk. Never silently treat an analysis-tool outage as a pass.
\section{Artifact checklist}
\begin{itemize}
\item Source and build recipe
\item Test cases and expected-versus-observed results
\item Tool versions and raw diagnostics
\item Security/portability caveats
\item Reviewer signature and corrective-action link
\end{itemize}
