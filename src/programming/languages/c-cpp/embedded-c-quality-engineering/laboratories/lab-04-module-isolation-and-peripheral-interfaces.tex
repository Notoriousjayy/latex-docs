\section{Purpose and prerequisites}
Linkage and testability. Prerequisites: C99 compiler, terminal, Git, access to an isolated test workspace and familiarity with the referenced study guide. This exercise is a proposed teaching protocol.
\section{Implementation specification}
\begin{enumerate}
\item Define separate public frame, transport and platform adapter interfaces.
\item Ensure each public header compiles alone in a dummy translation unit.
\item Use a fake transport dependency for host tests while excluding target-specific register headers.
\end{enumerate}

\section{Test matrix}
\begin{itemize}
\item Construct an explicit oracle for duplicate header include; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for null adapter; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for transport timeout; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for two independent encoder instances; record the input, expected return, observed result and environment.
\end{itemize}

\section{Execution and evidence}
\begin{enumerate}
\item Create an isolated source revision and record compiler, flags, architecture and optimization.
\item Run unit tests with positive, negative and boundary conditions; preserve complete output.
\item Run applicable compiler or SAST checks; distinguish tool-detected defects from manual review.
\item Record the source-to-test trace and an independent reviewer disposition.
\end{enumerate}

\section{Acceptance criteria}
Host parser builds without the MCU SDK, and external names are limited to declared API responsibilities.

\textbf{Control alignment:} EC-Q01 and EC-Q04.
\section{Failure analysis}
For any failed check, provide a minimized reproducer, causal explanation, correction, retest and residual risk. Never silently treat an analysis-tool outage as a pass.
\section{Artifact checklist}
\begin{itemize}
\item Source and build recipe
\item Test cases and expected-versus-observed results
\item Tool versions and raw diagnostics
\item Security/portability caveats
\item Reviewer signature and corrective-action link
\end{itemize}
