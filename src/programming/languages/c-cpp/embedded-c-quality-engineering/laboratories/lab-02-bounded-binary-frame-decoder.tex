\section{Purpose and prerequisites}
Untrusted input boundaries. Prerequisites: C99 compiler, terminal, Git, access to an isolated test workspace and familiarity with the referenced study guide. This exercise is a proposed teaching protocol.
\section{Implementation specification}
\begin{enumerate}
\item Specify a 0xA5 start byte, one-byte length, payload (maximum 32), XOR checksum and exact-frame-size contract.
\item Compile the included frame\_codec.c and test\_frame\_codec.c on a host using C99 with strict warnings.
\item Augment the test with exhaustive length values and a randomized byte-input corpus.
\end{enumerate}

\section{Test matrix}
\begin{itemize}
\item Construct an explicit oracle for empty payload; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for maximum payload; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for truncated frame; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for bad checksum; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for null output; record the input, expected return, observed result and environment.
\item Construct an explicit oracle for extra trailing data; record the input, expected return, observed result and environment.
\end{itemize}

\section{Execution and evidence}
\begin{enumerate}
\item Create an isolated source revision and record compiler, flags, architecture and optimization.
\item Run unit tests with positive, negative and boundary conditions; preserve complete output.
\item Run applicable compiler or SAST checks; distinguish tool-detected defects from manual review.
\item Record the source-to-test trace and an independent reviewer disposition.
\end{enumerate}

\section{Acceptance criteria}
Valid frames decode with the expected length and payload; all malformed inputs return explicit errors without writing a partial packet.

\textbf{Control alignment:} EC-Q02, EC-Q04 and EC-Q05.
\section{Failure analysis}
For any failed check, provide a minimized reproducer, causal explanation, correction, retest and residual risk. Never silently treat an analysis-tool outage as a pass.
\section{Artifact checklist}
\begin{itemize}
\item Source and build recipe
\item Test cases and expected-versus-observed results
\item Tool versions and raw diagnostics
\item Security/portability caveats
\item Reviewer signature and corrective-action link
\end{itemize}
