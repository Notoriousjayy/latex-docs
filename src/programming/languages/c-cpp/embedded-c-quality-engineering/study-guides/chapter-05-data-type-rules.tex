\begin{itemize}

\item Explain and verify integer promotions and conversion.
\item Explain and verify serialized data, fixed-point and bit-fields.
\end{itemize}

\section{Engineering concepts}
\subsection{Fixed-width representations}
Protocol widths are explicit contracts; determine which fixed-width types the target provides.

\subsection{Integer promotions and conversion}
Signedness and intermediate arithmetic can overflow or change interpretation despite fixed-width variables.

\subsection{Serialized data, fixed-point and bit-fields}
Serialize externally visible fields explicitly. Never assume native structure padding or bit-field order is a wire format.

\section{Practice laboratory}
Decode a big-endian length and perform checked accumulation, including zero and maximum cases.

Provide C99 source, two negative tests, two positive tests, toolchain data and a reviewer record.
\section{Failure investigation}
A length wraps before its capacity check and an oversized message is accepted. Reconstruct the failure, locate the broken invariant, design a reproducing test and document a mitigation.
