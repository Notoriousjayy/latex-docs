\section{Engineering concepts}
\subsection{Naming and units}
Readable names encode domain meaning and physical units when ambiguity is possible.

\subsection{Scope, initialization and reset}
Short lifetimes and explicit initialization simplify proofs that reads occur after writes.

\subsection{State ownership}
Reset and power recovery require explicit state invariants; mutable globals increase coupling.

\section{Practice laboratory}
Encapsulate a sensor sample cache and test invalid call ordering.

Provide C99 source, two negative tests, two positive tests, toolchain data and a reviewer record.
\section{Failure investigation}
A warm reset produces inconsistent valid flag and stale cached value. Reconstruct the failure, locate the broken invariant, design a reproducing test and document a mitigation.
