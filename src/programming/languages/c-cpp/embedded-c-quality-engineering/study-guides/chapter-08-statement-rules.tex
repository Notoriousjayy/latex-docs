\section{Source locator}
BARR-C:2018, Chapter 8: Statement Rules. This guide borrows the chapter topic only; explanations, questions and exercises are original.
\section{Learning outcomes}
\begin{itemize}
\item Explain and verify clear conditions.
\item Explain and verify exhaustive switch and bounded loops.
\item Explain and verify cleanup and error paths.
\end{itemize}

\section{Engineering concepts}
\subsection{Clear conditions}
Avoid hidden assignments inside decision predicates and keep failure outcomes obvious.

\subsection{Exhaustive switch and bounded loops}
Loop bounds should be finite and tested at zero and maximum lengths; define behavior for unknown states.

\subsection{Cleanup and error paths}
Error paths should preserve resource ownership and diagnostic information.

\section{Practice laboratory}
Implement a bounded finite-state frame parser and test malformed bytes and maximum inputs.

Provide C99 source, two negative tests, two positive tests, toolchain data and a reviewer record.
\section{Failure investigation}
A signed index compared with an unsigned bound behaves unexpectedly. Reconstruct the failure, locate the broken invariant, design a reproducing test and document a mitigation.
\section{Assessment questions}
\begin{enumerate}
\item Which assumptions are compiler- or target-specific?
\item Which defects can an analyzer detect, and which require manual or HIL review?
\item What objective evidence is sufficient for an independent reviewer?
\end{enumerate}

\section{Completion gate}
\begin{itemize}
\item Test evidence links to the source revision.
\item No unresolved critical defect or unapproved deviation.
\item At least one residual limitation is explicitly documented.
\end{itemize}
