\section{Purpose}
Original draft governance procedure; not product certification or an approved external standard.
\section{Steps}
\begin{enumerate}
\item Identify project rule, source span, device scope and exception identifier.
\item Assess cause, hazard severity, compensating controls and alternatives.
\item Request designated engineering and risk approval with review/expiry date.
\item Link approved exception in source-adjacent documentation where safe.
\item Review at expiry, product change or new safety evidence.
\end{enumerate}

\section{Decision constraints}
\begin{itemize}
\item Unapproved or expired deviations prevent release.
\item Unresolved critical hazards require escalation.
\item Record approver, date, source revision and retained evidence.
\end{itemize}
