\section{Purpose}
Original draft governance procedure; not product certification or an approved external standard.
\section{Steps}
\begin{enumerate}
\item Gather source revision, change intent, target build, hazards and test plan.
\item Examine memory, ranges, conversions, error paths and concurrency before cosmetic style.
\item Review documentation, naming and module interfaces.
\item Record finding, severity, repro, corrective change and retest.
\item Approve only with documented residual risk and authorized deviations.
\end{enumerate}

\section{Decision constraints}
\begin{itemize}
\item Unapproved or expired deviations prevent release.
\item Unresolved critical hazards require escalation.
\item Record approver, date, source revision and retained evidence.
\end{itemize}
