\section{Purpose}
Original draft governance procedure; not product certification or an approved external standard.
\section{Steps}
\begin{enumerate}
\item Freeze source and toolchain revision with target identifiers.
\item Run warning-clean builds, unit, SAST, target, HIL and timing tests.
\item Triage findings and confirm exception validity.
\item Compile traceable requirement, test and hazard evidence.
\item Record approver, release/rollback plan and archival location.
\end{enumerate}

\section{Decision constraints}
\begin{itemize}
\item Unapproved or expired deviations prevent release.
\item Unresolved critical hazards require escalation.
\item Record approver, date, source revision and retained evidence.
\end{itemize}
