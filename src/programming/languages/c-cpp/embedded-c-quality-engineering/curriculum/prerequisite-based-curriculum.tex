\section{Prerequisites}

\section{Competency gates}
\begin{itemize}
\item Explain integer conversion and buffer ownership before implementing a parser.
\item Demonstrate a reproducible compilation and test process.
\item Distinguish analyzer coverage from manual review and target hardware tests.
\item Demonstrate triage of a deliberately injected defect in an isolated fixture.
\end{itemize}

\section{Capstone}
Deliver a transport-independent frame decoder with explicit maximum input size, C99 tests, an approved control matrix, static-analyzer evidence and a release recommendation.
\section{Suggested scoring}
Correctness and portability 30 percent; security 25 percent; testing 25 percent; evidence quality 20 percent. Teaching threshold: 80 percent and zero unresolved critical findings. Not a published standard.
