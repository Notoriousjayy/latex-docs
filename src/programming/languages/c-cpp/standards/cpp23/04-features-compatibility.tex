\section{Migration policy}
The seventh edition is C++23 as published in October 2024. Its informative Annex C is the correct starting point for source compatibility analysis with the 2020, 2017, 2014, 2011 and earlier editions. Annex D identifies retained compatibility features. Neither annex is a promise that all historical programs remain well-formed.

\section{Explicit object parameter (deducing this)}
\anchorref{9.3.4.6; Foreword}
\textbf{Change class:} new in C++23.\quad \textbf{Capability probe:} \_\_cpp\_explicit\_this\_parameter.

Reduces duplicated cv/ref-qualified member overloads; explicit object syntax has constraints on eligible functions.

\standard{The 2024 standard documents the relevant language/library behavior at 9.3.4.6; Foreword. Check exact conditions before relying on the summarized feature.}
\begin{lstlisting}[language=C++]
struct Vector2 {
  double x, y;
  double norm2(this const Vector2& self) {
    return self.x*self.x + self.y*self.y;
  }
};
\end{lstlisting}
\practice{Migration gate: run a representative compile test, at least one semantic regression test, and a fallback decision for unsupported vendor configurations.}
