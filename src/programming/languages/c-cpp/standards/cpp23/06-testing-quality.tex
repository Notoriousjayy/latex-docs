\section{Test architecture and pass criteria}
A rigorous verification system has layers: compile conformance, deterministic functional tests, safety instrumentation, concurrency tests, integration, performance and artifact controls. Each layer tests a different claim; none alone establishes program-wide conformance or security.

\section{Language and library conformance probes}
\anchorref{4; 16.4}
Feature support must be tested separately for parser, library, runtime and target. A -std=c++23 flag is not a certificate that every facility is available.

\standard{The standard locators determine which language/library property is under test; the tools and quality gates are independent engineering controls.}
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=3pt]
\item Define one falsifiable property and its test oracle.
\item Preserve toolchain identity and machine-readable evidence.
\item Capture limitations and false-negative conditions.
\end{itemize}
\begin{lstlisting}[language=C++]
#include <version>
#ifndef __cpp_lib_expected
#error "std::expected feature macro unavailable"
#endif
// Probe a tiny valid use in a separate target.
\end{lstlisting}
\practice{Do not upgrade tool output to a claim of blanket ISO conformity.}
\takeaway{Acceptance evidence: Store the probe source, compile command, stdout/stderr and chosen fallback.}

\section{Example GitHub Actions workflow (illustrative)}
\begin{lstlisting}[language=]
name: cpp23-quality
on: [push, pull_request]
jobs:
  build-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Configure
        run: cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
      - name: Build
        run: cmake --build build --parallel
      - name: Test
        run: ctest --test-dir build --output-on-failure
\end{lstlisting}
This example intentionally omits pinned SHA values and a fixed compiler image; production policies should supply both. Separate ASan, UBSan and TSan matrices, plus feature probes for new library APIs. Do not infer a C++23 facility works because the compiler accepts the command-line language flag.
