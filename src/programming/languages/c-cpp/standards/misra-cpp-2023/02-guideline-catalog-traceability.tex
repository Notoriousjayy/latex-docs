\section{Matrix legend and change governance}
D = Decidable; U = Undecidable; TU = Single Translation Unit; SYS = System. The dash denotes that decidability and analysis scope are not assigned to directives. Always keep the complete guideline identifier (including Rule or Dir), rather than replacing it with a tool vendor check number.

Catalog changes require an edition/errata impact assessment, a version-controlled patch to data/guidelines.csv, and rerunning of tool mapping tests. Any change to a project recategorization belongs in its compliance plan, not this source-level baseline.
