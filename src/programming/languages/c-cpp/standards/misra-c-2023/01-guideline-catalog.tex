\section{How to read this catalog}
Every row is tied to a specific entry in the uploaded MISRA C:2023 publication. The \textbf{audit cue} is an independently worded control objective, \emph{not the original normative text}. Review the exact requirement, its amplification and exceptions in the licensed PDF before making a compliance decision. Source locations identify 1-based PDF pages in the provided file.
\subsection{Abbreviations}
\textbf{M}: Mandatory; \textbf{R}: Required; \textbf{A}: Advisory. \textbf{D}: Decidable; \textbf{U}: Undecidable; \textbf{TU}: Single Translation Unit; \textbf{SYS}: System. The edition list includes C90, C99 or C11; C11 also means C18. Directives do not have D/U or TU/SYS attributes.

\section{Working with classification data}
A guideline that is not applicable to the selected C edition must be recorded as not applicable rather than silently excluded. A rule marked as ``decidable'' in the standard does not establish that a particular tool detects every breach. System-scope checks depend on a complete or defensibly bounded view of linked source and interfaces. Excluded third-party source and generated code must be accounted for in the project's compliance plan.
\section{Traceability and independence controls}
Link each entry to: (1) a verification method and version, (2) project applicability, (3) checker identifiers, (4) one or more positive/negative validation tests where practical, (5) approved deviations, and (6) release evidence. Treat the accompanying CSV as an index, not as proof of conformance.
