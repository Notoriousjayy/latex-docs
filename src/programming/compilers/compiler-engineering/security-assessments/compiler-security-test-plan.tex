\section{Security review workflow}
\begin{enumerate}
\item Identify trust boundary, assets, attacker-controlled input and entry points.
\item Enumerate failure modes and measurable controls.
\item Create a negative corpus and bound every fuzz or generated input.
\item Run under isolated CI with time/memory budgets; attach sanitized logs.
\item Triage reproducible findings and require remediation or explicit accepted risk.
\end{enumerate}

\section{Release blockers}
\begin{itemize}
\item Known uncontrolled code execution from an input source.
\item Reproducible memory corruption in supported configurations.
\item Semantic mismatch without bounded and documented input restrictions.
\item Missing build provenance for a production-delivered compiler artifact.
\end{itemize}
