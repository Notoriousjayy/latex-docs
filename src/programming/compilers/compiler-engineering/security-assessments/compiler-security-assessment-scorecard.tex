\section{Rating rules}
Score each control on evidence: 0 = absent; 1 = designed but not tested; 2 = operating with incomplete evidence; 3 = passing tests with reproducible evidence; 4 = independently reviewed and sustained. Compute an unweighted total out of 20, but retain individual critical findings; a high total cannot override an exploitable high-severity defect.\par
\section{Release blockers}
\begin{itemize}
\item Known uncontrolled code execution from an input source.
\item Reproducible memory corruption in supported configurations.
\item Semantic mismatch without bounded and documented input restrictions.
\item Missing build provenance for a production-delivered compiler artifact.
\end{itemize}
