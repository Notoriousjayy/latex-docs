\section{Scope and interfaces}
\sourceanchor{Book chapters 9,11,12,13,14.}
Each lab follows the source concept and uses an independently authored example/tool contract. Programs in this package are intentionally small teaching implementations; extensions are specified tasks, not claimed implemented features.

\section{Build and safety protocol}
\begin{enumerate}
\item Record compiler/interpreter version and immutable source revision.
\item Use isolated local inputs; reject oversized sources; do not execute code emitted from untrusted input.
\item Run correctness and negative tests first, then relevant sanitizers and bounded fuzzing.
\item Keep a baseline trace and a separate optimized trace.
\item Complete the lab review form and capture observed rather than expected results.
\end{enumerate}

\section{Lab C5: C++ worklist liveness}
\subsection{Implementation task}
Solve backward data flow; validate input graph and worklist termination.
\textbf{Reference or extension status:} \texttt{code/cpp/dataflow.cpp}.\par\subsection{Acceptance criteria}
