\section{Scope and interfaces}
\sourceanchor{Book chapters 2,3,4,5.}
Each lab follows the source concept and uses an independently authored example/tool contract. Programs in this package are intentionally small teaching implementations; extensions are specified tasks, not claimed implemented features.

\section{Build and safety protocol}
\begin{enumerate}
\item Record compiler/interpreter version and immutable source revision.
\item Use isolated local inputs; reject oversized sources; do not execute code emitted from untrusted input.
\item Run correctness and negative tests first, then relevant sanitizers and bounded fuzzing.
\item Keep a baseline trace and a separate optimized trace.
\item Complete the lab review form and capture observed rather than expected results.
\end{enumerate}

\section{Lab P1: Maximal-munch scanner}
\subsection{Implementation task}
Define token classes and priority; assert byte/character span boundaries; produce a token list and explicit EOF.
\textbf{Reference or extension status:} \texttt{code/python/lexer.py, code/python/test\_compiler.py}.\par\subsection{Acceptance criteria}
All accepted samples round-trip to the expected token sequence; bad characters raise a position-aware error.
\subsection{Controlled experiments}
\begin{itemize}
\item One ordinary input, one empty/boundary input, and one adversarially malformed input.
\item Record elapsed time or iteration count only after correctness passes.
\item State the invariant preserved and at least one known limitation.
\end{itemize}
