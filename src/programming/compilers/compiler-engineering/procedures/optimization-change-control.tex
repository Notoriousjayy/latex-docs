\section{Purpose and entry criteria}
Make semantic assumptions testable in each rewrite.
	extbf{Entry:} immutable revision, defined compiler semantics, reproducible test command, reviewer.

\section{Controlled procedure}
\begin{enumerate}
\item \textbf{Define precondition}: Specify operand types, overflow and exceptional behavior, aliasing and effects.
\item \textbf{Declare effect}: List affected IR instructions, dominance relationships and invalidated analyses.
\item \textbf{Establish proof}: Provide a local equivalence argument or a clearly labeled bounded empirical surrogate.
\item \textbf{Counterexamples}: Test NaN, signed zero, integer boundary, exceptions, side effects and aliasing if applicable.
\item \textbf{Re-measure}: Benchmark equal inputs in fixed environment after correctness gate.
\item \textbf{Document decision}: Keep/rollback decision including compile time, runtime and safety impact.
\end{enumerate}

\section{Failure handling}
On an unexpected crash, semantic mismatch, excessive memory or missed test gate: stop release eligibility, capture a minimized reproducer, isolate tooling, and review the root cause. Never classify a speedup as acceptable if the transformation is incorrect.
