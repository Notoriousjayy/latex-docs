\section{Purpose and entry criteria}
Preserve meaning before optimizing cost.
	extbf{Entry:} immutable revision, defined compiler semantics, reproducible test command, reviewer.

\section{Controlled procedure}
\begin{enumerate}
\item \textbf{Formal boundary}: Specify language semantics, undefined behavior, observable effects and target model.
\item \textbf{Test taxonomy}: Acceptance/rejection, boundary, diagnostic, round-trip, differential and metamorphic cases.
\item \textbf{Independent oracle}: Compare AST evaluator, IR interpreter, and native result where representable.
\item \textbf{Analysis consistency}: Recompute CFG edges, symbol tables, dominance and liveness after relevant mutations.
\item \textbf{Security controls}: Apply size/time limits, sanitizer testing and resource-constrained execution.
\item \textbf{Evidence review}: Archive fixture, seed, command, exit status, log digest and defect disposition.
\end{enumerate}

\section{Failure handling}
On an unexpected crash, semantic mismatch, excessive memory or missed test gate: stop release eligibility, capture a minimized reproducer, isolate tooling, and review the root cause. Never classify a speedup as acceptable if the transformation is incorrect.
