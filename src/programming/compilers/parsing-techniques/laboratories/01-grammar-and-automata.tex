\section{Purpose and source alignment}
Implement reachability/productivity, construct and minimize a deterministic automaton.\PTSource{Chapter 2 and 5.}
\section{Entry requirements}
State the target grammar family, the API, expected behavior on empty input, configured limits, and any structural output. Complete corresponding chapter study guides first.
\section{Workload and required artifact}
For the grammar S -> A; A -> aA | a; X -> x, X is unreachable; test empty and a, aa, x.
\section{Procedure}
\begin{enumerate}\item Specify grammar and token contract with positive and negative fixtures.\item Write a minimal oracle, expected trace and invariants before implementation.\item Implement in Python and C++ where the laboratory is supported; label exploratory pseudocode separately.\item Add deterministic unit tests, including malformed inputs and limit-exceeded results.\item Record measured inputs and results with separate raw data if benchmarking.\item Perform review against the paired laboratory record Template; complete the Blank form during the session.\end{enumerate}
\section{Correctness and adversarial acceptance criteria}
Validate empty strings, dead state behavior, and deterministic transitions.\par\textbf{Hardening gate.} Detect unreachable symbols, nonproductive cycles and malformed transition tables.
\section{Submission evidence}
\begin{itemize}\item Source revision and compiler/interpreter versions.\item Unit test command and exact output, including rejected cases.\item Coverage of required fixtures and one minimized failure example.\item Complexity reasoning with the grammar family and output obligations.\item Signed peer review and security/benchmark form references where applicable.\end{itemize}
