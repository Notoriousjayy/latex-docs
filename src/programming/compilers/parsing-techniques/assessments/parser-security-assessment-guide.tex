\section{Scope and assumptions}
A parser may consume untrusted source: source code, templates, configuration, documents or protocol payloads. Its output is not trusted simply because it is syntactically valid. This guide adds modern software-security controls to the book's treatments of ambiguity, algorithm families, error handling and practical implementation.\PTSource{Chapters 3, 4, 7, 11, 16, 17; security methodology is a contemporary extension.}
\section{Assets, boundaries and attacker objectives}
Assets include integrity of AST/IR, availability of parsing services, consistent diagnostics, memory safety, and isolation of semantic actions. Trust boundaries: bytes-to-decoder, decoder-to-lexer, token-to-parser, parse-tree-to-semantic-pass, and diagnostics-to-logs. Consider attackers controlling grammar definitions separately from attackers controlling source inputs.

\section{Mandatory secure-parser invariants}
\begin{enumerate}\item Every input path has a maximum byte length and a deterministic rejection status.\item Every iterative closure and graph traversal deduplicates work and has finite bounds.\item Every AST or forest allocation counts toward a node budget.\item Errors never trigger unchecked semantic execution, evaluation or code emission.\item Every failure has an unambiguous status: lexical, syntax, semantic, resource-limit or internal.\item Native implementations pass sanitizer builds and must not rely on undefined behavior.\end{enumerate}
\section{Fuzzing protocol}
Seed with both valid and invalid syntactic samples. Apply mutations to individual tokens, boundaries, nesting depth, UTF-8, numeric magnitude, nullable cycles, and ambiguous alternatives. For each observed crash or timeout, minimize the input, record exact binary+build flags+seed, and add a regression. Distinguish harness errors from parser errors. Maintain an internal severity gate for memory corruption, nontermination and unsafe execution.
\section{Assessment decision}
A passing mean score does not override an exploitable crash, a known unbounded input path, or silent recovery that proceeds to execution. Record the remaining attack surface, accepted limitations, ownership, and test evidence; reassess after parser or grammar changes.
