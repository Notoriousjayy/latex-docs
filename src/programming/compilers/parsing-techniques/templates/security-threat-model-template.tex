\section{Instructions and evidence requirements}
Model malicious inputs and malicious grammar definitions separately; a parser must fail closed under configured limits. Ratings, if applicable, use 0 (no evidence), 1 (partial), 2 (baseline), 3 (adversarially validated), 4 (independently reproduced). A safety-critical failure is a release blocker regardless of arithmetic score.
