\section{Instructions and evidence requirements}
Demonstrate distinct parse trees; distinct left/right derivation orders alone do not prove ambiguity. Ratings, if applicable, use 0 (no evidence), 1 (partial), 2 (baseline), 3 (adversarially validated), 4 (independently reproduced). A safety-critical failure is a release blocker regardless of arithmetic score.
