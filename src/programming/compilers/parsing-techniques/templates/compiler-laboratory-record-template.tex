\section{Instructions and evidence requirements}
Attach token traces, AST examples and semantic diagnostics. No reported results without executable evidence. Ratings, if applicable, use 0 (no evidence), 1 (partial), 2 (baseline), 3 (adversarially validated), 4 (independently reproduced). A safety-critical failure is a release blocker regardless of arithmetic score.
