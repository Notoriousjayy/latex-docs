\section{Instructions and evidence requirements}
Capture repeatable seeds and environment; triage ASan/UBSan as correctness and security findings. Ratings, if applicable, use 0 (no evidence), 1 (partial), 2 (baseline), 3 (adversarially validated), 4 (independently reproduced). A safety-critical failure is a release blocker regardless of arithmetic score.
