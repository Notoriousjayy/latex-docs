\section{Instructions and evidence requirements}
Recovery is not correction; no recovered source may silently proceed to compilation or execution. Ratings, if applicable, use 0 (no evidence), 1 (partial), 2 (baseline), 3 (adversarially validated), 4 (independently reproduced). A safety-critical failure is a release blocker regardless of arithmetic score.
