\section{Decision procedure}
Start with requirements: guaranteed grammar class; ambiguity policy; whether a single AST or shared forest is needed; expected input length/distribution; streaming/incremental demands; error diagnostic requirements; and resource budget. Only then select a parser.\PTSource{Chapters 3--14 and 17.}

\section{Choice record}
Document alternatives, why a more powerful parser was necessary, complexity assumptions, reliability consequences, evidence and rejected options. A benchmark that measures only recognition must not be compared to one building a complete parse forest without accounting for work differences.
