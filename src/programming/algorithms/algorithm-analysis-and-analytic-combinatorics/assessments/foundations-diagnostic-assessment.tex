\section{Instructions and permitted aids}
Allow 90 minutes and a non-networked calculator or local Python interpreter. State assumptions explicitly; support every exact answer with either a derivation or an exhaustive small-size check. This assessment is original to this suite, not a reproduction of textbook exercises.
\section{Mathematical diagnostic (40 points)}
\begin{enumerate}
\item (8 points) Prove by induction that $\sum_{k=1}^n k(k+1)=n(n+1)(n+2)/3$.
\item (8 points) Derive $a_n$ when $a_0=1$ and $a_n=3a_{n-1}+2$; verify $n=2$.
\item (8 points) Let $X$ be the number of heads in four independent fair tosses. Give its PGF, expectation and variance.
\item (8 points) Derive the number of inversions in reverse-sorted $n$-element arrays, then compare it to the uniform-permutation expected count.
\item (8 points) Write an OGF and extract $[z^n](1-z)^{-3}$ without numerical curve fitting.
\end{enumerate}
\section{Model critique (30 points)}
A report states: ``Inserting uniformly random keys in a BST produces a uniform random binary tree shape; therefore all Catalan tree path-length formulas apply.'' Identify the unsupported step, supply two precise random-tree distributions, and propose an exact $n=3$ check.
\section{Experiment design (30 points)}
Create a factorial benchmark of two sorting algorithms against three input distributions and four sizes. Specify input generation, operation counts, elapsed-time measurements, controls, deterministic seeds, and one threat to validity. Include a publication-ready CSV header.
\section{Scoring standard}
Mathematical correctness (50 points), justified assumptions and model semantics (25), and reproducible experimental practice (25). Require 80 points overall and no zero on the model-critique task for the next curricular stage. Record revisions in the proof-assessment form.
