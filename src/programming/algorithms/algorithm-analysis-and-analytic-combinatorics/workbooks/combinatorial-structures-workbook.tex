\section{Object definitions}
A model specifies not just $n$ but whether trees are uniformly sampled by shape, by insertion permutation, or generated by some other process; whether strings are i.i.d.; and whether mapping outputs are independent.
\section{Worked calibration}
For $m$ independent keys assigned uniformly to $b$ buckets, each key pair collides with probability $1/b$. Thus the expected number of colliding pairs is $\binom{m}{2}/b$.
