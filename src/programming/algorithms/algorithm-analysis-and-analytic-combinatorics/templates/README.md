## Quality contract

LaTeX roots contain `\documentclass` and are intended to be compiled by `latex-docs` build tooling; the original textbook is required for authoritative chapter study. Template guidance is not completed project evidence. All blank forms contain empty response fields, not bracketed placeholders.
