# Python algorithm implementations

Python 3.11+ original educational baselines with differential and exhaustive small-instance tests.

```sh
python3 -m unittest -v
python3 benchmark.py --max-power 12 --repeats 15 --batch 20 --csv results.csv
```

The standalone reference algorithms include the ring buffer, Euclid GCD, LCG (not secure), Fisher–Yates, stable insertion/merge sorting, lower-bound binary search, combinations, permutations, n-queens, exact cover and DPLL SAT. Benchmark CSV is generated by running the harness; no fabricated data is included.
