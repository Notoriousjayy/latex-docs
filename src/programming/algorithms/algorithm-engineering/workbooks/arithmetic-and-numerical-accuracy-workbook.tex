\section{Worked model: Horner's rule}
Evaluate $p(x)=2x^3-3x^2+4x-5$ as $((2x-3)x+4)x-5$. The Horner form uses three multiplications and three additions/subtractions, versus potentially many repeated power evaluations. The real-arithmetic identity does not ensure bit-for-bit floating-point equivalence for every evaluation strategy.
\section{Worked model: Euclidean reduction}
For $a=252,b=105$, division gives $252=2(105)+42$, $105=2(42)+21$, $42=2(21)+0$, so the GCD is 21. The remainder measure decreases while nonzero. For machine integers, the handling of negative inputs and minimum representable values must be made explicit.

\section{Workbook protocol}
Write assumptions before derivations. Distinguish claims to prove, counterexamples to find and empirical questions to test. Use separate paper if a proof exceeds the available lines. Each response should end with a testable implication or explicit limitation.
