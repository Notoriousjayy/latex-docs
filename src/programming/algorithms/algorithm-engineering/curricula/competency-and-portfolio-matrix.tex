\section{Assessment scale}
Scores are 0 absent, 1 emerging, 2 functional with substantial guidance, 3 independently defensible, and 4 production-grade evidence with trade-off discussion. Assign scores per dimension; do not infer high proficiency from only a fast benchmark.

\section{Portfolio release checklist}
\begin{itemize}
\item Public repository contains original code and authored explanations, not scanned source-book content.
\item All experimental figures link to raw data and parameter configuration.
\item CI runs Python unit tests and C++ compilation/tests with zero unexpected failures.
\item Failures and TODOs are visible; no benchmark plots conceal missing observations.
\item Each capstone includes what the data cannot conclude.
\end{itemize}
