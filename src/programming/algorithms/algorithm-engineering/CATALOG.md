# Document Catalog and Learning Path

**Source foundation:** Knuth's *The Art of Computer Programming*, Volumes 1 (third edition), 2 (third edition), 3 (second edition), 4A (2011), and 4B (2022).

## Recommended first-use sequence

1. `technical-references/volume-and-section-crosswalk.tex` — select source volume and chapter boundaries.
2. `curricula/prerequisite-based-curriculum.tex` — adopt the 24-week plan and prerequisite gates.
3. `study-guides/volume-1-fundamental-algorithms.tex` — begin with formal specification and information structures.
4. `laboratories/python-algorithm-implementation-labs.tex` — work through the Python tracks; pair with the C11 or C++20 manual.
5. `workbooks/asymptotic-and-proof-workbook.tex` — establish written mathematical evidence.
6. `procedures/reproducible-benchmarking-procedure.tex` — use before interpreting performance results.
7. `templates/algorithm-design-scorecard-template.tex` — learn criteria, then print its `blank/` companion.
