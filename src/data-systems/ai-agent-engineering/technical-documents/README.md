# AI Agent Engineering — Technical Documents

## Overview

Standalone technical references that complement the [AI Agent Engineering curriculum](../README.md). These documents describe proposed designs and implementation techniques, not deployed or independently certified agent systems.

## Documents

- [AI Agent Harness Architecture and Engineering Guide](ai-agent-harness-architecture-and-engineering-guide.tex) — an editable, self-contained LaTeX reference with an architecture diagram, eight harness components, a bounded Python control-loop example, context and memory management, security guardrails, verification evidence, an eight-phase roadmap, and a practical repository-aware coding-agent laboratory.
- [AGENTS.md: Repository-Aware Guidance for AI Coding Agents](agents-md-repository-guidance.tex) — a pdfLaTeX-compatible engineering reference covering instruction-file conventions, scope and overrides, agent security controls, and a repository-specific implementation plan with a reusable AGENTS.md template.

## Build and validation

From the repository root:

```bash
make preflight
make build-category-data-systems
```

To compile the document independently:

```bash
cd src/data-systems/ai-agent-engineering/technical-documents
latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error ai-agent-harness-architecture-and-engineering-guide.tex
```

The source uses an editable, native TikZ architecture diagram and requires no external image assets. LaTeX outputs are generated by the repository build and deployment workflows rather than committed alongside the source.
