\section{Structural, behavioral and information architecture}
\subsection{Packaged and explicit assembly}
The local MemAgent facade and live factory differ. The same synthetic domain is exercised through alternative implementations rather than a common deployment. The explicit ERPA graph exposes memory, meaning, model, dispatch and persistence responsibilities. Live MongoDB and Oracle substrates are documented; actual live provider calls are not verified.\par\textbf{Evidence:} P01-EVD-002, P01-EVD-003, P01-EVD-004, P01-EVD-005, P01-EVD-006, P01-EVD-007, P01-EVD-008.\par

\subsection{Response caching and memory}
The cache lookup receives the message while the insertion receives user\_id. Inspect partitioning and invalidation before claiming principal isolation. A hit bypasses ordinary context, model and persistence work. A miss assembles recalled records, context card, disclosed skills, tools and governed meaning; explicit preferences and working-turn data are stored. Live checkpointing is distinct from the offline compact checkpoint. Part 3 provider prefix caching must not be conflated with response caching.\par\textbf{Evidence:} P01-EVD-006, P01-EVD-009, P01-EVD-010, P01-EVD-011, P01-EVD-012, P01-EVD-014, P01-EVD-016.\par

\subsection{Tool authority and operations}
The offline graph includes a capability-missing calendar path; documented MCP integration is not proof of executed calls. Separate draft and execution require principal-bound approval and replay safety. Scratch promotion and scheduler boundaries need tests. Compose describes a configuration only. The six staged construction scripts are inventoried; their individual behavior is not fully traced.\par\textbf{Evidence:} P01-EVD-013, P01-EVD-015, P01-EVD-017, P01-EVD-018, P01-EVD-019.\par

\subsection{Advanced workflow and isolation}
The workflow API and durable stores separate run and approval state. Supplier tools compute evidence freshness, sanctions checks, scoring and report verification. Host recomputation precedes remote execution, so sandboxing does not eliminate host trust. The local subprocess profile is not proof of isolation. Recovery proof exists but was not run.\par\textbf{Evidence:} P01-EVD-020, P01-EVD-021, P01-EVD-022, P01-EVD-023, P01-EVD-029.\par

\subsection{Ontology, research and evaluation}
Total Recall, research and MetaHarness are separate teaching systems. Memory alternatives, session approvals and evaluation protocol identity are observed. Ontology refresh, parallel research and fair-comparison outcomes require deeper call-site and notebook review. No latency, cost or evaluation superiority is asserted.\par\textbf{Evidence:} P01-EVD-024, P01-EVD-025, P01-EVD-026, P01-EVD-027, P01-EVD-028, P01-EVD-030.\par
