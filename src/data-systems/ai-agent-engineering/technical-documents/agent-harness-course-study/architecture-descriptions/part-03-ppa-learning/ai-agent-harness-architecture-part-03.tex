\section{Structural, behavioral and information architecture}
\subsection{Retained versus changed core}
Approval, memory, policy, scratch, scheduler and tools have identical selected blob prefixes in Parts 2 and 3. Agent, model, workspace, MCP and System One differ. This does not establish behavioral equivalence or deployment parity. The graph still separates proposal from execution authority, and replay forces effects into approval.\par\textbf{Evidence:} P03-EVD-002, P03-EVD-004, P03-EVD-005, P03-EVD-006, P03-EVD-007, P03-EVD-008, P03-EVD-009, P03-EVD-010, P03-EVD-011, P03-EVD-012, P03-EVD-013.\par

\subsection{Prompt caching and cost}
Stable instructions and dynamic context are accounted separately. Inclusive input counts subtract cache reads/writes; raw provider reports may already exclude them. Four billed categories are multiplied by configured per-million prices. Scripted rows cost zero; this is not a live invoice or measured cost saving. Part 1 returns a cached answer before inference; Part 3 prefix caching does not bypass inference.\par\textbf{Evidence:} P03-EVD-003, P03-EVD-013, P03-EVD-014.\par

\subsection{Trajectories and candidate learning}
Layer sizes and plan are recorded; the trajectory tracks actual tool calls, skills and outcomes. Repeated eligible signatures inform drafting. Model-generated or templated candidate skills are procedural adaptation, not weight training. Preserve the distinction between proposal, effect, approval and successful outcome.\par\textbf{Evidence:} P03-EVD-002, P03-EVD-015, P03-EVD-016, P03-EVD-017.\par

\subsection{Five checks and activation}
The gate performs real-tool-name, regression, held-out, approval-contract and replay checks. A gate lock protects evaluation, trial changes the live pointer and restores it, and all checks must pass. Cost is report-only. promote rejects non-PASSED versions; activate moves to any stored version. Evaluate authorization and rollback eligibility, and whether concurrent normal requests observe the trial pointer. Corrections route to skill, memory or neither.\par\textbf{Evidence:} P03-EVD-018, P03-EVD-019, P03-EVD-020, P03-EVD-021.\par

\subsection{Scorecard semantics}
Six blocking checks: zero attacks obeyed, zero unapproved outward effects, zero tasks from quarantine, ten of ten frozen procedure selections, complete effect audit, zero duplicate open tasks per source. Cache-read share, median model seconds and median cost are reported. WorkspaceError replaces quarantine IDs with an empty set and note: READY may not establish screening coverage. Require missing evidence to become UNKNOWN or BLOCKED.\par\textbf{Evidence:} P03-EVD-022, P03-EVD-014, P03-EVD-015.\par

\subsection{Research and teaching}
The separate paper graph adds budget tally and reflection. Researcher subgraphs invoke tools and compact context; reader memory, vocabulary and research skills are separate from learned PPA skills. Budget helpers are not proof of a hard external cost ceiling. Packaged gateway and teaching API are distinct boundaries; notebook behavior and MemoRizz internals remain partial.\par\textbf{Evidence:} P03-EVD-024, P03-EVD-025, P03-EVD-026, P03-EVD-027, P03-EVD-028, P03-EVD-029, P03-EVD-030, P03-EVD-031, P03-EVD-032.\par

\subsection{Evolution and proposed safeguards}
Persistent learned procedures increase the trust surface relative to Part 2. Govern all activation routes, isolate candidate evaluation, record consent and provenance, enforce cost limits separately and require scorecard evidence completeness. These are proposals, not implemented features.\par\textbf{Evidence:} P03-EVD-002, P03-EVD-014, P03-EVD-019, P03-EVD-022.\par
