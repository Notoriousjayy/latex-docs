\section{System overview and drivers}
\subsection{Retained versus changed core}
Approval, memory, policy, scratch, scheduler and tools have identical selected blob prefixes in Parts 2 and 3. Agent, model, workspace, MCP and System One differ. This does not establish behavioral equivalence or deployment parity. The graph still separates proposal from execution authority, and replay forces effects into approval.\par\textbf{Evidence:} SAD-P03-EVD-2, SAD-P03-EVD-4, SAD-P03-EVD-5, SAD-P03-EVD-6, SAD-P03-EVD-7, SAD-P03-EVD-8, SAD-P03-EVD-9, SAD-P03-EVD-10, SAD-P03-EVD-11, SAD-P03-EVD-12, SAD-P03-EVD-13.\par

\subsection{Prompt caching and cost}
Stable instructions and dynamic context are accounted separately. Inclusive input counts subtract cache reads/writes; raw provider reports may already exclude them. Four billed categories are multiplied by configured per-million prices. Scripted rows cost zero; this is not a live invoice or measured cost saving. Part 1 returns a cached answer before inference; Part 3 prefix caching does not bypass inference.\par\textbf{Evidence:} SAD-P03-EVD-3, SAD-P03-EVD-13, SAD-P03-EVD-14.\par

\subsection{Trajectories and candidate learning}
Layer sizes and plan are recorded; the trajectory tracks actual tool calls, skills and outcomes. Repeated eligible signatures inform drafting. Model-generated or templated candidate skills are procedural adaptation, not weight training. Preserve the distinction between proposal, effect, approval and successful outcome.\par\textbf{Evidence:} SAD-P03-EVD-2, SAD-P03-EVD-15, SAD-P03-EVD-16, SAD-P03-EVD-17.\par

\subsection{Five checks and activation}
The gate performs real-tool-name, regression, held-out, approval-contract and replay checks. A gate lock protects evaluation, trial changes the live pointer and restores it, and all checks must pass. Cost is report-only. promote rejects non-PASSED versions; activate moves to any stored version. Evaluate authorization and rollback eligibility, and whether concurrent normal requests observe the trial pointer. Corrections route to skill, memory or neither.\par\textbf{Evidence:} SAD-P03-EVD-18, SAD-P03-EVD-19, SAD-P03-EVD-20, SAD-P03-EVD-21.\par

\subsection{Scorecard semantics}
Six blocking checks: zero attacks obeyed, zero unapproved outward effects, zero tasks from quarantine, ten of ten frozen procedure selections, complete effect audit, zero duplicate open tasks per source. Cache-read share, median model seconds and median cost are reported. WorkspaceError replaces quarantine IDs with an empty set and note: READY may not establish screening coverage. Require missing evidence to become UNKNOWN or BLOCKED.\par\textbf{Evidence:} SAD-P03-EVD-22, SAD-P03-EVD-14, SAD-P03-EVD-15.\par

\subsection{Research and teaching}
The separate paper graph adds budget tally and reflection. Researcher subgraphs invoke tools and compact context; reader memory, vocabulary and research skills are separate from learned PPA skills. Budget helpers are not proof of a hard external cost ceiling. Packaged gateway and teaching API are distinct boundaries; notebook behavior and MemoRizz internals remain partial.\par\textbf{Evidence:} SAD-P03-EVD-24, SAD-P03-EVD-25, SAD-P03-EVD-26, SAD-P03-EVD-27, SAD-P03-EVD-28, SAD-P03-EVD-29, SAD-P03-EVD-30, SAD-P03-EVD-31, SAD-P03-EVD-32.\par

\subsection{Evolution and proposed safeguards}
Persistent learned procedures increase the trust surface relative to Part 2. Govern all activation routes, isolate candidate evaluation, record consent and provenance, enforce cost limits separately and require scorecard evidence completeness. These are proposals, not implemented features.\par\textbf{Evidence:} SAD-P03-EVD-2, SAD-P03-EVD-14, SAD-P03-EVD-19, SAD-P03-EVD-22.\par
