\section{System overview and drivers}
\subsection{Packaged and explicit assembly}
The local MemAgent facade and live factory differ. The same synthetic domain is exercised through alternative implementations rather than a common deployment. The explicit ERPA graph exposes memory, meaning, model, dispatch and persistence responsibilities. Live MongoDB and Oracle substrates are documented; actual live provider calls are not verified.\par\textbf{Evidence:} SAD-P01-EVD-2, SAD-P01-EVD-3, SAD-P01-EVD-4, SAD-P01-EVD-5, SAD-P01-EVD-6, SAD-P01-EVD-7, SAD-P01-EVD-8.\par

\subsection{Response caching and memory}
The cache lookup receives the message while the insertion receives user\_id. Inspect partitioning and invalidation before claiming principal isolation. A hit bypasses ordinary context, model and persistence work. A miss assembles recalled records, context card, disclosed skills, tools and governed meaning; explicit preferences and working-turn data are stored. Live checkpointing is distinct from the offline compact checkpoint. Part 3 provider prefix caching must not be conflated with response caching.\par\textbf{Evidence:} SAD-P01-EVD-6, SAD-P01-EVD-9, SAD-P01-EVD-10, SAD-P01-EVD-11, SAD-P01-EVD-12, SAD-P01-EVD-14, SAD-P01-EVD-16.\par

\subsection{Tool authority and operations}
The offline graph includes a capability-missing calendar path; documented MCP integration is not proof of executed calls. Separate draft and execution require principal-bound approval and replay safety. Scratch promotion and scheduler boundaries need tests. Compose describes a configuration only. The six staged construction scripts are inventoried; their individual behavior is not fully traced.\par\textbf{Evidence:} SAD-P01-EVD-13, SAD-P01-EVD-15, SAD-P01-EVD-17, SAD-P01-EVD-18, SAD-P01-EVD-19.\par

\subsection{Advanced workflow and isolation}
The workflow API and durable stores separate run and approval state. Supplier tools compute evidence freshness, sanctions checks, scoring and report verification. Host recomputation precedes remote execution, so sandboxing does not eliminate host trust. The local subprocess profile is not proof of isolation. Recovery proof exists but was not run.\par\textbf{Evidence:} SAD-P01-EVD-20, SAD-P01-EVD-21, SAD-P01-EVD-22, SAD-P01-EVD-23, SAD-P01-EVD-29.\par

\subsection{Ontology, research and evaluation}
Total Recall, research and MetaHarness are separate teaching systems. Memory alternatives, session approvals and evaluation protocol identity are observed. Ontology refresh, parallel research and fair-comparison outcomes require deeper call-site and notebook review. No latency, cost or evaluation superiority is asserted.\par\textbf{Evidence:} SAD-P01-EVD-24, SAD-P01-EVD-25, SAD-P01-EVD-26, SAD-P01-EVD-27, SAD-P01-EVD-28, SAD-P01-EVD-30.\par
