# Workflow

Map criteria to tests; include positive, negative and boundary cases; preserve existing assertions; report coverage gaps.

## Boundaries
Use only approved tools, paths and data. Stop on policy denial or ambiguous scope.

## Evidence
Return the task ID, source paths, changes (if authorized), verification evidence and limitations. Never claim unobserved success.
