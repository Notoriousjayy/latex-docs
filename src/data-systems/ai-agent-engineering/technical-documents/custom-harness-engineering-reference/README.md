# Companion implementation
Run from this directory: `python -m unittest discover -s tests`. Run the external verifier with `python -m harness.verify --workspace .`. Run the final-log diagnostic gate with `python -m harness.verify --latex-log /path/to/final.log` (also require successful build, PDF presence and convergence separately).

Configuration files are documentation-verified examples, not live-agent tested. Install copies at the paths documented in the guide, not in production blindly. The MCP URLs are deliberately invalid placeholders; replace only with a reviewed server. The hook command refers to an administrator-owned location; the provided observer does not enforce policy. The CI example is illustrative and requires pinned actions, a trusted verification source, branch rules and independent review. The runner executes repository tests; therefore run it inside an independently constrained disposable environment with no production credentials. A worktree is not a security boundary. The test fixtures validate runner logic, not vendor sandbox security.
