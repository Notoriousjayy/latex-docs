\section{Role-specific tracks}
\begin{itemize}
\item Database engineers focus on schema invariants, migration proofs, query plans and concurrency.
\item Enterprise architects focus on boundaries, canonical semantics and decision traceability.
\item AppSec and governance reviewers focus on sensitive data access, retention, lineage and audit evidence.
\item Data engineers focus on fact grain, late-arriving records and semantic consistency across reports.
\end{itemize}

\section{Assessment policy}
Assess working artifacts, not recognition of terminology. Require each participant to explain one alternative model and why it was rejected. Score decisions on testable invariants, data ownership, operational cost and architectural fitness.
