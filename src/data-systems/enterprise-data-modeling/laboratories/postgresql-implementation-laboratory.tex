\section{Environment and safety}
Use an isolated PostgreSQL 16+ disposable development database and psql with ON\_ERROR\_STOP enabled. The scripts reset named demo tables within the edm schema. Never run them in a shared or production database. Examples deliberately omit enterprise requirements such as authorization, high availability, privileged posting enforcement, and production-safe migration orchestration.


\section{Execution order}
\begin{enumerate}
\item Create a disposable database with psql or a local container.
\item Run the scripts in numerical order from laboratories/sql; halt on any failure.
\item Capture constraint errors and the final results returned by the smoke tests.
\item Re-run in a fresh database and record the time, database version, and evidence location.
\end{enumerate}

\section{Evaluation checklist}
\begin{itemize}
\item Every required foreign key must reject an orphan reference.
\item At least one business invariant must be justified beyond simple row constraints.
\item Transaction boundaries must be explicit and independently reviewable.
\item Show a corrected migration plan for names that cannot be safely split on spaces.
\item Explain how direct DML privileges would violate a trusted financial posting API.
\end{itemize}
