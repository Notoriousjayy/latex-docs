\begin{CornellOverviewBox}{Chapter overview}
\textbf{Purpose.} Model large-scale evolutionary change as reversals of blocks in unsigned and signed permutations and reason about rearrangement distance.

\textbf{Learning objectives}
\begin{itemize}
  \item Encode gene order as a permutation.
  \item Define unsigned and signed reversals.
  \item Use adjacencies, breakpoints, strips, and bounds to guide sorting.
  \item Explain why orientation information changes the algorithmic problem.
\end{itemize}

\textbf{Prerequisites.} Permutations, greedy algorithms, graph cycles, approximation, and genome orientation.
\end{CornellOverviewBox}

\begin{CornellNotesTable}
\CornellNoteRow{\S19.1: Why use a genome-level model?}{Point edits cannot describe inversions or other events that move long blocks. Abstract a chromosome by the order of unique markers or syntenic blocks. The model ignores nucleotide detail to focus on large-scale organization.}
\CornellNoteRow{How is a genome represented?}{Choose one genome as the identity order $(1,2,\ldots,n)$. Represent the other as a permutation of the same markers. Add sentinel elements at both ends when defining adjacencies so incorrect boundary placement is counted consistently.}
\CornellNoteRow{What is rearrangement distance?}{Given an allowed operation set, the distance is the minimum number or total cost of operations transforming one genome representation into the other. It is model dependent: allowing reversals, transpositions, duplications, or unequal gene content yields different problems.}
\CornellNoteRow{\S19.2: What is an unsigned inversion?}{Choose positions $i\le j$ and reverse the order of the block $\pi_i,\ldots,\pi_j$. Marker orientation is ignored. A reversal can repair boundary adjacencies but may also disrupt correct internal structure, so a purely local greedy choice needs analysis.}
\CornellNoteRow{What are breakpoints and strips?}{An adjacency is correct when neighboring values are consecutive in the target order under the chosen unsigned convention. A breakpoint is an incorrect adjacency. Maximal runs without internal breakpoints are strips. A reversal changes only the adjacencies at its two boundaries, giving lower bounds on the number of required reversals.}
\CornellNoteRow{How does a breakpoint-guided method work?}{Select a reversal that removes breakpoints or creates longer target-consistent strips, repeat, and finish when no breakpoints remain. Correctness requires that zero breakpoints implies the target under the sentinel convention. Approximation analysis compares progress per reversal with the maximum progress any reversal can make.}
\CornellNoteRow{Why are lower bounds useful?}{If one reversal can remove at most a fixed number of breakpoints, the current breakpoint count divided by that number bounds the optimum from below. Comparing an algorithm's operation count with this bound yields an approximation ratio, but only for the exact breakpoint definition and model used.}
\CornellNoteRow{What makes unsigned sorting difficult?}{Ignoring orientation loses information about how a reversed block should face. Local adjacency choices can conflict, and exact unsigned reversal distance is computationally hard in the general model. Practical solutions use approximation, branch-and-bound, or domain constraints.}
\CornellNoteRow{\S19.3: What is a signed inversion?}{Each marker carries an orientation sign. Reversing a block reverses its order and flips every sign. The target is usually $(+1,+2,\ldots,+n)$. Orientation makes adjacencies more informative and permits stronger graph-based structure.}
\CornellNoteRow{How do signed algorithms use graph cycles?}{Split signed markers into oriented extremities and connect observed adjacencies with target adjacencies in a breakpoint graph. Alternating cycles measure preserved structure; a reversal rewires boundary edges and changes the cycle decomposition. Exact distance formulas may require additional obstruction terms beyond a simple breakpoint count.}
\CornellNoteRow{What implementation issues matter?}{Normalize marker names, verify one-to-one content before forming a permutation, define circular versus linear chromosomes, handle multiple chromosomes explicitly, and apply sign flips to the entire reversed block. Duplicated or missing markers require a richer model.}
\CornellNoteRow{\S19.4: What should practice emphasize?}{Apply signed and unsigned reversals by hand, compute sentinels and breakpoints, construct a small breakpoint graph, and distinguish a lower bound, an approximation guarantee, and an exact distance result.}
\end{CornellNotesTable}

\begin{CornellSummaryBox}{Chapter synthesis}
Genome rearrangement models compress each conserved block to a permutation element and measure evolution by block operations. Unsigned reversals change order only and support breakpoint-guided bounds but lose orientation information. Signed reversals also flip orientation and admit a richer breakpoint-graph analysis. Every distance claim is meaningful only relative to the chosen markers and operation set.
\end{CornellSummaryBox}

\begin{CornellSummaryBox}{Key takeaways}
\begin{CornellRecallList}
  \item Rearrangement distance is defined by an operation model.
  \item A reversal changes only two external block boundaries.
  \item Breakpoint counts provide lower bounds, not automatically exact distances.
  \item Unsigned reversal distance is harder because orientation is absent.
  \item A signed reversal reverses order and flips signs.
\end{CornellRecallList}
\end{CornellSummaryBox}

\begin{CornellOverviewBox}{Algorithm selection: when to use this}
\begin{CornellChecklist}
  \item Use unsigned permutations when marker orientation is unavailable or intentionally ignored.
  \item Use signed permutations when block orientation is known.
  \item Use breakpoint bounds to evaluate greedy or approximate solutions.
  \item Use graph-based signed methods when exact orientation-aware distance is required.
\end{CornellChecklist}
\end{CornellOverviewBox}

\begin{CornellExamBox}{Self-test questions}
\begin{CornellRecallList}

\end{CornellRecallList}
\end{CornellExamBox}
