\section*{Cornell notes}
\begin{longtable}{@{}Q!{\color{Mist}\vrule width 1pt}A@{}}\cornellhead
\cue{What is Newton form?}{For nodes $x_1,\ldots,x_{n-1}$,
\[
f(x)=a_1+a_2(x-x_1)+\cdots+a_n\prod_{j=1}^{n-1}(x-x_j).
\]
Power form uses all nodes zero; Taylor form uses all nodes $c$; factorial form uses $x_j=j-1$.}
\cue{How is VALUE computed?}{Nested multiplication begins with the highest coefficient and repeatedly applies $v\leftarrow a_k+(z-x_k)v$ while moving downward. This is Horner's rule generalized to nonidentical Newton nodes.}
\cue{What does NEWTON change?}{Replace the first node $x_1$ by $z$ while leaving later nodes fixed. The updated coefficients satisfy a backward recurrence $b_n=a_n$ and $b_k=a_k+(z-x_k)b_{k+1}$. Substitution shows the old and new expansions are identical.}
\cue{How is a Taylor shift obtained?}{Repeatedly introduce the node $c$ into a power-form expansion. The in-place triangular loop adds $c$ times the next coefficient while processing indices backward, so unread coefficients are preserved. Repeating yields coefficients in powers of $x-c$.}
\cue{What is STIRLING?}{Convert power coefficients to falling-factorial coefficients in the basis $(x)_m=x(x-1)\cdots(x-m+1)$ by introducing nodes $0,1,\ldots$. Applied to a monomial, the output gives Stirling numbers of the second kind.}
\cue{What is REVERSE STIRLING?}{Reverse the transformation from falling-factorial to ordinary power coefficients by introducing the complementary node sequence. Applied to one factorial polynomial, the output gives signed Stirling numbers of the first kind.}
\cue{How are the operations unified?}{The inner procedure NWT varies a lower index, a shift $z$, an increment parameter, and whether intermediate nested values are stored. POLY's option selects ordinary or factorial evaluation, a requested number of Taylor coefficients, STIRLING, or REVERSE STIRLING.}
\cue{In-place invariants and cautions}{Backward index order is essential because later coefficients are needed before overwrite. $N-1$ is the degree, so the array has $N$ coefficients. The source routine uses integer arithmetic; modern applications must select a numeric type compatible with coefficient growth and division-free transforms.}
\cue{Retrieval practice}{\begin{enumerate}\item Which nodes define power form?\item What is the nested VALUE update?\item Why process backward?\item Which Stirling family maps powers to falling factorials?\item What does a positive Taylor option control?\end{enumerate}}
\end{longtable}
\begin{tcolorbox}[colback=Ink!4,colframe=Ink,title=Cornell summary]
POLY treats ordinary powers, Taylor powers, and falling factorials as Newton bases with different node sequences. A generalized Horner recurrence evaluates a Newton expansion. The same backward recurrence changes one node while preserving the represented polynomial; repeated node changes produce Taylor shifts and the forward or reverse Stirling transforms. A shared inner loop lets one option-driven routine perform all operations, sometimes overwriting the coefficient array and sometimes returning only a value. The main implementation invariant is backward traversal so an update never destroys a coefficient still required by the recurrence.
\end{tcolorbox}
