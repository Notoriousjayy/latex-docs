\begin{tcolorbox}[colback=Paper,colframe=Ink]{\small\bfseries\color{Teal}CORNELL NOTES}\par{\LARGE\bfseries Chapter 29: Random Unlabeled Rooted Trees (RANRUT)}\par\medskip\textbf{Topic:} Recursive uniform sampling over rooted-tree shapes\hfill\textbf{Date:} \today\par\textbf{Study purpose:} Convert a counting recurrence into an exact random generator.\end{tcolorbox}
\begin{tcolorbox}[colback=Teal!5,colframe=Teal,title=Essential question]How can a weighted recursive decomposition sample every rooted-tree isomorphism class of size $n$ with equal probability?\end{tcolorbox}
\begin{tcolorbox}[colback=white,colframe=Mist,title=Learning objectives]\begin{itemize}\item Distinguish unlabeled rooted shapes from labeled trees.\item Interpret the recurrence for $t_n$.\item Derive the branch probabilities.\item Trace the two-stack implementation.\item State why the output distribution is uniform.\end{itemize}\textbf{Prerequisites:} rooted trees, isomorphism, recurrences, conditional probability.\end{tcolorbox}
\section*{Cornell notes}
\begin{longtable}{@{}Q!{\color{Mist}\vrule width 1pt}A@{}}\cornellhead
\cue{What is sampled?}{Two rooted trees are equivalent when a root-preserving graph isomorphism maps one to the other. The sample space contains one object for each such unlabeled shape, so automorphisms and numbers of possible vertex labelings do not alter its probability.}
\cue{Counting recurrence}{If $t_n$ is the number of unlabeled rooted trees on $n$ vertices, then
\[(n-1)t_n=\sum_{d\geq1}\sum_{j\geq1\,:\,jd<n} d\,t_d\,t_{n-jd}.\]
The pair $(j,d)$ describes attaching $j$ identical copies of a size-$d$ rooted tree to a distinguished root position in a residual tree of size $n-jd$.}
\cue{Branch probability}{Choose a legal pair $(j,d)$ with probability
\[\Pr(j,d\mid n)=\frac{d\,t_d\,t_{n-jd}}{(n-1)t_n}.\]
The recurrence proves these weights sum to $1$, so no rejection step is required once the counts are available.}
\cue{Recursive construction}{Independently generate $T'$ of size $n-jd$ and $T''$ of size $d$. Make $j$ copies of $T''$ and attach all of their roots to the root of $T'$. The resulting rooted tree has $(n-jd)+jd=n$ vertices.}
\cue{Why uniform?}{Inductively, the recursive trees are uniform for their sizes. The factor $d$ and the normalization $(n-1)t_n$ compensate for the number of decompositions representing a final shape. Summing all construction histories for any fixed shape gives probability $1/t_n$.}
\cue{Two-stack execution}{A control stack stores unresolved decomposition instructions such as $(j,d)$ and a marker such as $(j,0)$ for the later combining step. A tree stack stores completed subtrees. The algorithm expands instructions until base cases are reached, then combines returned subtrees without recursive procedure calls.}
\cue{Base cases and space}{The one-vertex rooted tree is immediate (and the two-vertex case is unique). Each decomposition reduces positive sizes, so termination is guaranteed. Total pending sizes are bounded by the target size, giving linear-order stack storage once the $t_k$ table is available.}
\cue{Numerical implementation}{The counts grow rapidly. Sample by selecting an integer in $1..(n-1)t_n$ and locating its cumulative weight interval, using exact integer arithmetic. Floating-point probabilities can introduce bias or make the last interval unreachable.}
\cue{Common misconception}{This is not the same experiment as uniformly labeling vertices and then forgetting the labels: tree shapes have different automorphism groups and hence different numbers of labelings. Uniformity here is explicitly over isomorphism classes.}
\cue{Retrieval practice}{\begin{enumerate}\item What does $t_n$ count?\item What does $(j,d)$ mean?\item Why do branch weights normalize?\item What is stored on each stack?\item Why can labeling-and-forgetting be biased?\end{enumerate}}
\end{longtable}
\begin{tcolorbox}[colback=Ink!4,colframe=Ink,title=Cornell summary]
RANRUT samples uniformly from unlabeled rooted-tree shapes. A recurrence decomposes a size-$n$ tree into a residual tree and $j$ equal branches of size $d$; its summands become the exact probabilities for choosing $(j,d)$. Recursive uniform subtrees are then combined, and the weighted multiplicity of all histories gives every final shape probability $1/t_n$. A pair stack controls expansion and combination while a tree stack holds completed pieces. Exact integer interval selection preserves the intended distribution.
\end{tcolorbox}
