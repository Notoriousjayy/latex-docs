\begin{tcolorbox}[colback=Teal!5,colframe=Teal,title=Essential question]How can every equivalence relation on $\{1,\ldots,n\}$ be generated once while class labels remain canonical?\end{tcolorbox}
\begin{tcolorbox}[colback=white,colframe=Mist,title=Learning objectives]\begin{itemize}\item State the disjoint, nonempty cover conditions.\item Interpret the recursive partition tree.\item Find and move the highest active element.\item Maintain class populations and membership labels.\item Explain canonical class naming and termination.\end{itemize}\textbf{Prerequisites:} set partitions, equivalence classes, arrays, recursive trees.\end{tcolorbox}
\section*{Cornell notes}
\begin{longtable}{@{}Q!{\color{Mist}\vrule width 1pt}A@{}}\cornellhead
\cue{What is a set partition?}{A family of nonempty, pairwise disjoint classes whose union is $\{1,\ldots,n\}$. Class order and order within a class have no mathematical significance. The same object is an equivalence relation, with classes as equivalence classes.}
\cue{What recursive tree is used?}{A partition of $n$ elements with $k$ classes has $k+1$ descendants on $n+1$ elements: insert $n+1$ into any existing class, or create a new singleton class. A horizontal level of this tree contains all partitions of a fixed ground set.}
\cue{How is the successor found?}{Locate the largest active element $m$: the largest element not forced to remain a singleton in the current suffix. Move $m$ from its current class to the next class, creating a new class if needed, and move all later elements $m+1,\ldots,n$ back to class 1.}
\cue{What arrays are maintained?}{$q_i$ is the class containing element $i$; $p_j$ is the population of class $j$; $n_c$ is the number of classes. Moving $m$ decrements $p_{q_m}$, increments $p_{q_m+1}$, and may extend $n_c$. Reset suffix elements contribute to class 1.}
\cue{How are labels canonical?}{Classes are numbered in order of first appearance: the least element of class $j$ is the first element not belonging to an earlier class. This restricted-growth convention gives each unlabeled set partition one unique array $q$, eliminating duplicates caused by arbitrary class names.}
\cue{Initialization and final state}{Initialize all elements in class 1: $q_i=1$, $p_1=n$, $n_c=1$. The final partition has every element in its own class, $q_i=i$ and $n_c=n$. The more-to-come flag becomes false at that state.}
\cue{Correctness basis}{The recursive tree orders descendants by the destination class of the new element. Backing up to the largest movable element, increasing its branch, and resetting the suffix to first branches is ordinary lexicographic path succession. Hence each canonical path, and therefore each set partition, appears exactly once.}
\cue{Cautions}{Do not interpret numeric class labels as part of the mathematical object. Keep $p$ synchronized with $q$, especially while resetting the suffix. The search for $m$ assumes a valid current restricted-growth representation.}
\cue{Retrieval practice}{\begin{enumerate}\item What makes classes a partition?\item Why are there $k+1$ descendants?\item Which element is active?\item What does $p_j$ store?\item Why does canonical naming prevent duplicates?\end{enumerate}}
\end{longtable}
\begin{tcolorbox}[colback=Ink!4,colframe=Ink,title=Cornell summary]
NEXEQU enumerates set partitions by viewing them as paths in a recursive tree. A node with $k$ classes produces descendants by placing the next element in one of those classes or in a new singleton. The successor algorithm backs up to the largest element whose class choice can advance, moves it to the next class, and resets all later elements to the first class. Membership and class-population arrays make the transition local. A restricted-growth naming rule assigns class labels by first occurrence, so each unlabeled partition has one representation. The all-in-one-class state starts the sequence and the all-singletons state ends it.
\end{tcolorbox}
