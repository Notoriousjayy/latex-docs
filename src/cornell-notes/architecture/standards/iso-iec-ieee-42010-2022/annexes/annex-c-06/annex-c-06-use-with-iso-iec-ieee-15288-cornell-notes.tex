\CornellNoteRow{Core details}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item The concept of architecture Here is consistent with the architecture definition process of ISO/IEC/IEEE 15288.
\item However, ISO/IEC/IEEE 15288 places requirements on an AD in addition to those herein.
\item Specifically, an architecture definition needs to include an identification of the architecture entities included in the system and an allocation of key stakeholder concerns and critical system requirements to those items.
\item These can be achieved in various ways, such as by creating decomposition and allocation architecture viewpoints, or through use of correspondences.
\end{itemize}}
