\begin{CornellNotesTable}
\CornellNoteRow{Purpose / key concept}{A template for the specification of architecture viewpoints is presented.}
\CornellNoteRow{Core details}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item An architecture viewpoint that is documented in this form meets the requirements of 8.1.
\item The template identifies the contents of a specification of an architecture viewpoint.
\item Each element of the content includes its name (B.2.X), and a brief description of its intended content, and guidance for developing that content.
\item In some cases, additional contents are nested within top-level description contents of the specification.
\end{itemize}}
