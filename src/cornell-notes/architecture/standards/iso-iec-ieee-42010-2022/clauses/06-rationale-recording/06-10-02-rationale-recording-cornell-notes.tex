\begin{CornellOverviewBox}{Overview}
{\Large\bfseries\textcolor{CNavy}{Section 6.10.2: Rationale recording}}\\[3pt]
{\small\textbf{Classification:} Normative}\\
{\small\textbf{Learning objective:} Identify the mandatory, recommended, and permitted provisions governing rationale recording.}
\end{CornellOverviewBox}
\vspace{3pt}

\begin{CornellNotesTable}
\CornellNoteRow{Purpose}{Establishes when rationale is mandatory and when rationale or evidence is recommended for viewpoints, frameworks, languages, alternatives, and limitations.}
\CornellNoteRow{Requirement}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item A conforming architecture description must include or reference rationale for each essential architecture decision (per 6.10.1).
\end{itemize}}
\CornellNoteRow{Recommendation}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item An architecture description should include or reference a rationale for each architecture viewpoint selected for use (per 6.6).
\item An architecture description should include or reference a rationale for each ADF and each ADL selected for use.
\item An architecture description should include or reference evidence of consideration and rationale for selection of alternatives.
\item An architecture description should include a rationale for an AD limitation (e.g. resource problem, timing problem, and effort avoided for well-known description already covered by other ADs).
\end{itemize}}
\CornellNoteRow{Related sections}{6.6, 6.10.1}
\CornellNoteRow{Conformance check}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item A conforming architecture description must include or reference rationale for each essential architecture decision (per 6.10.1)
\end{itemize}}
\CornellNoteRow{Active recall}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item Which provisions in Rationale recording are mandatory for conformance?
\item Which provisions are recommendations or permissions rather than requirements?
\end{itemize}}
\end{CornellNotesTable}


\begin{CornellSummaryBox}{Summary}
Establishes when rationale is mandatory and when rationale or evidence is recommended for viewpoints, frameworks, languages, alternatives, and limitations. For conformance, its mandatory provisions must be satisfied, including: A conforming architecture description must include or reference rationale for each essential architecture decision (per 6.10.1). Recommended practice includes: An architecture description should include or reference a rationale for each architecture viewpoint selected for use (per 6.6).
\end{CornellSummaryBox}
