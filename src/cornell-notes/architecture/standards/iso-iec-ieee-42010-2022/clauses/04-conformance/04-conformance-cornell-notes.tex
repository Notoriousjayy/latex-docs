\begin{CornellNotesTable}
\CornellNoteRow{Purpose}{Defines five types of conformance claims and connects each claim to its applicable requirement set; tailoring is not permitted when claiming conformance.}
\CornellNoteRow{Core details}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item The requirements Here are contained in Clauses 6, 7 and 8.
\item There are five situations in which claims of conformance with the provisions of This section can be made.
\end{itemize}}
\CornellNoteRow{Requirement}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item 1) When conformance is claimed for an architecture description, the claim must demonstrate that the specification of the architecture description meets the requirements listed in Clause 6.
\item 2) When conformance is claimed for an architecture description framework, the claim must demonstrate that the specification of the architecture description framework meets the requirements listed in 7.1.
\item 3) When conformance is claimed for an architecture description language, the claim must demonstrate that the specification of the architecture description language meets the requirements listed in 7.2.
\item 4) When conformance is claimed for an architecture viewpoint, the claim must demonstrate that the specification of the architecture viewpoint meets the requirements listed in 8.1.
\item 5) When conformance is claimed for a model kind, the claim must demonstrate that the specification of the model kind meets the requirements listed in 8.2.
\end{itemize}}
\CornellNoteRow{Related sections}{7.1, 7.2, 8.1, 8.2}
\CornellNoteRow{Conformance check}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]
\item 1) When conformance is claimed for an architecture description, the claim must demonstrate that the specification of the architecture description meets the requirements listed in Clause 6
\item 2) When conformance is claimed for an architecture description framework, the claim must demonstrate that the specification of the architecture description framework meets the requirements listed in 7.1
\end{itemize}}
\CornellNoteRow{Active recall}{\begin{itemize}[leftmargin=*,nosep,topsep=1pt]

\begin{CornellSummaryBox}{Summary}
Defines five types of conformance claims and connects each claim to its applicable requirement set; tailoring is not permitted when claiming conformance. For conformance, its mandatory provisions must be satisfied, including: 1) When conformance is claimed for an architecture description, the claim must demonstrate that the specification of the architecture description meets the requirements listed in Clause 6; 2) When conformance is claimed for an architecture description framework, the claim must demonstrate that the specification of the architecture description framework meets the requirements listed in 7.1.
\end{CornellSummaryBox}
