\begin{CornellNotesTable}
\CornellNoteRow{Term}{\textbf{architecture description language}}
\CornellNoteRow{Definition}{A means of architectural expression with defined syntax and semantics, representations, conventions, and associated rules.}
\CornellNoteRow{Distinction}{An ADL is a language for expression; an ADF is a broader set of conventions, principles, and practices for organizing architecture descriptions.}
\CornellNoteRow{Example / application}{Architecture Analysis and Design Language (AADL), ArchiMate, UML, SysML, UAF Profile.}

\begin{CornellSummaryBox}{Summary}
A means of architectural expression with defined syntax and semantics, representations, conventions, and associated rules. An ADL is a language for expression; an ADF is a broader set of conventions, principles, and practices for organizing architecture descriptions.
\end{CornellSummaryBox}
