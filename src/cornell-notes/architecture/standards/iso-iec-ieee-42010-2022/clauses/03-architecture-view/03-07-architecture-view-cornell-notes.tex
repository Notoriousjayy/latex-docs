\begin{CornellNotesTable}
\CornellNoteRow{Term}{\textbf{architecture view}}
\CornellNoteRow{Definition}{An identifiable information part that forms a portion of an architecture description.}
\CornellNoteRow{Distinction}{A view is architecture information produced for an entity; a viewpoint provides the conventions that govern such views.}
\CornellNoteRow{Example / application}{An Information or Data View addresses information-relevant concerns framed by an Information viewpoint. It contains as view components (3.19), a conceptual data model, a data management model and a data access model and correspondences linking those components together.}

\begin{CornellSummaryBox}{Summary}
An identifiable information part that forms a portion of an architecture description. A view is architecture information produced for an entity; a viewpoint provides the conventions that govern such views.
